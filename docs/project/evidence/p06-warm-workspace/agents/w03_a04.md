## Delivered behavior

The pure API is:

```python
analyze_processes(processes, raw_logs, *, build_bindings, contract, expected_revision)
```

It accepts the 24 runner process rows in the frozen order, raw log text keyed
by process ID, and the complete two build-binding documents keyed by
`simx-fp16` and `simx-bf16`. It reconstructs each process binding from the
same-format build and fixed plan, recomputes qualification IDs, requires one
clean source snapshot across formats, checks the exact contract identity, and
revalidates every raw log through the trusted record reader. The parsed raw
observation must equal the retained observation exactly, including numeric
types. Missing, duplicated, reordered, replaced, failed and mismatched samples
cannot be silently removed or relabeled.

The analyzer validates the separate supervised-duration containment check and
requires 32 positive integer timed durations and a positive available cycle
delta in every batch. All 24 excluded primes and both complete warm-up pairs
remain visible in diagnostics. The decision population is five batch means
per format and policy. Each policy reports minimum, maximum, median and
population standard deviation; means, medians, variance and comparison ratios
retain exact numerator/denominator values alongside readable floating values.

The three frozen criteria are evaluated through integer cross-products and
integer comparisons: candidate median at most 95% of reference, no slower
measured paired batch, and no increase in any paired cycle delta. Both formats
must meet all three. A valid negative result reports
`hypothesis_evaluation=not_supported` while keeping
`raw_record_validation=pass`. Invalid observations raise `AnalysisError` and
produce no statistical result. No threshold, baseline, fixture or native
runtime code changed.

The optional CLI reads at most 64 MiB of regular UTF-8 JSON, rejects duplicate
fields/nonfinite constants/deep nesting, takes the expected source revision
separately, and creates an output file exclusively. It will not overwrite an
existing file.
