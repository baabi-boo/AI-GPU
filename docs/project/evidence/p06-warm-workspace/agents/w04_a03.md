## Actual validation

**Passed: 21 test methods in 18.870 seconds, exit status 0**, on CPython
3.12.14 with Debian C++ 14.2.0 and GNU Make 4.4.1. The final run recorded
**682 counted rejection checks**, plus five directly asserted invalid-format
rejections. An earlier version passed the same 21 methods in 18.624 seconds;
the final rerun verifies an independently stated required-option inventory
and a more precise test name.

Two separate temporary build trees were freshly configured for RV64
`p02-tfr`, FP16 and BF16. The actual generated Makefiles produced untouched
runtime, SimX backend, kernel, host and linker stamp lines with `PERF=1` and
one build job. `CC`, `CXX`, `VX_CC` and `VX_CXX` were replaced by a failing
sentinel for stamp generation; the sentinel was never invoked. No native
backend or kernel object was compiled.

The host C++ preprocessor then produced **eight actual effective-header
observations**, one per format and compiler role, using each original role's
macro arguments, include order and working directory. Expected hardware maps
were generated separately through `ci/gen_config.py` and the generated
`VX_config.h`, rather than copied from the validator's expected-map constants.
All eight matched. `PERF_ENABLE=1` was present only in the backend; the other
three roles remained counter-selector free. Original raw line SHA-256 values
and ordered include paths remain represented in each validated role record.

The suite covers:

- Missing and conflicting profile, format, RV64, native TFR/STD arithmetic,
  geometry, release and derived configuration selectors in each role.
- Missing, disabled, repeated, forwarded and misplaced performance selectors;
  debug, functional simulation, multithreading, tracing and alternate backend
  settings, including misleading zero-valued definitions.
- Required warning, optimization, standard, dependency-output and kernel
  ISA/ABI options; missing, repeated, weakened or extra options fail.
- Exact role include order, source/build roots and backend dependency target;
  omitted, duplicated, reordered, unbound, parent-traversing and forwarded
  include inputs fail.
- The exact four observer wrappers, their order and runtime library binding;
  missing, duplicated, additional or redirected linker inputs fail.
- Shell syntax, response files, injected source/output operands, malformed
  records, controls, Unicode separators, nontext values and byte bounds.
- Effective-header mode/arithmetic drift, unknown configuration, failed or
  malformed preprocessor output, duplicate definitions, excess macro records,
  incorrect expected maps and unsupported roles/backends.
- Strict backend/format/job values, including rejection of booleans as job
  counts, and cross-format source/build record substitution.

Identical repeated non-performance definitions are deliberately normalized by
the inherited shared reader. A dedicated positive test verifies that such a
repeat preserves the effective configuration while changing the original
record hash. This differs from the performance selector's explicit
single-occurrence requirement; no normalization rule was weakened here.
