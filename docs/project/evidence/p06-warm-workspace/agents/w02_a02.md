## Implementation

The new reader checks an externally digest-pinned original ZIP through the
existing pinned trusted archive reader. It never extracts members, imports
retained Python, executes retained commands or opens recorded absolute paths
on the local host. It requires the complete frozen selected-variant report,
clean expected source identity, all source/build/snapshot/log bytes, independent
fixtures, unchanged profile/kernel, exact ordered commands and bounded resource
receipts. Runtime/backend/kernel/host/compiler and linker records are revalidated
from their original stamp bytes; original effective-header logs are checked.

For each policy it reconstructs the entire execution binding and qualification
hash, parses the original raw log with the trusted workspace reader, and compares
the recomputed observation with the embedded report. Required packet members
are inventoried exactly. A four-archive aggregator rejects duplicates, missing
variants, mixed source trees, incompatible common tool/dependency identities and
mixed hosted run/attempts. A successful result remains retained-data replay and
does not accept performance or a phase.

Public APIs:

```python
replay_archive(path, sha256, *, expected_revision, expected_backend,
               expected_format, prefix="workspace")
replay_matrix(archives, *, expected_revision)
```

Each matrix input is `{path, sha256, backend, format}`. CLI inputs use repeated
`--archive BACKEND:FORMAT:SHA256:ABSOLUTE_PATH` and `--source-revision`; `--output`
creates a new report without replacing an existing file. The CLI requires all
four variants; the Python selected-variant API reports its partial scope.

## Limits and follow-up

The reader checks packet consistency against supplied identities, not the
honesty of an arbitrary producer. Binary/tool identities do not recreate the
complete original host installation. Simulator allocator observations do not
establish physical reclamation, and processor RTL bypasses the AFU. Warm timing,
P06-A02/A03, vendor P01-A03 and physical hardware qualification remain separate.
Independent hunk review and mutation coverage are required before publication.
