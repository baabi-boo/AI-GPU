## Implemented boundary

`replay_archive(path, sha256, *, expected_revision, prefix="warm-workspace")`
uses the existing digest-pinned bounded ZIP reader without extracting or executing
members. The standard-library implementation reuses the reviewed workspace
reader's descriptor, inventory, command, resource-budget and recorded-path helpers.
It validates the complete new warm packet: two format builds, 53 supervised
commands, 52 ordered stability observations and all 24 policy processes.

The reader reconstructs the common build bindings and each process binding,
checks unchanged source/tool/dependency observations and retained source/config
bodies, reproduces compiler/linker and effective-header validation with backend
`PERF_ENABLE`, and re-parses all raw numerical, dispatch, ownership, timing and
counter observations. It checks supervisor duration containment, exact process
ordering, final counts, retained-member completeness and false acceptance flags.
The same build ID applies to every policy batch of each format.

Hosted packets additionally require the retained job/workflow/interpreter,
successful preparation, cache quarantine and final execution receipts. Cache
product hashes are identities; their bodies are not retained. The analyzer is
called only after packet checks complete. A valid `not_supported` hypothesis
remains a passing evidence replay; it does not become a failed execution or an
accepted phase.
