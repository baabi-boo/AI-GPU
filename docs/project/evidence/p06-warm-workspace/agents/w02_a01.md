## Implemented

Frozen `p06-warm-workspace-v1` as a separate same-source/same-binary, two-policy
experiment. The contract binds the 17 immutable fixture, independent producer,
profile, kernel, ABI and counter-definition inputs without applying the obsolete
cold runtime pins to new code. It defines the exact record fields, native
statuses, sample chronology, poison sequence, bounded observer accounting,
32-call primary timing population, counter/memory boundaries, resource budgets
and predetermined rejection criteria.

The API supplies `expected_contract`, `load_contract`, `select_cases`,
`process_plan` and `poison_for`. Its fixed matrix contains 24 processes,
792 launches, 25,344 exact words and 640 measured operations. Duplicate fields,
wrong numeric types, unsupported selections, source drift, unbounded files and
symlink traversal fail closed. The same-build matching rule was selected in
independent W01 design/runtime reviews before any performance samples.

A build inspection found that SimX counter observation requires `PERF=1` and
backend `PERF_ENABLE`; the correctness validator rejects this mode. Root and
the runner worker were notified to use a separate warm compiler validator,
preserving the old contracts. The caller must also retain successful submit's
`complete=false`, while wait and close require `complete=true`.
