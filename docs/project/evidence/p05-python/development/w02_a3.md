## Implemented contract

Exports: `Tensor`, `Session`, `Operation`, `ModelOperation`, `ExecutionStatus`,
`ModelStatus`, `BindingError`, `build_info`, `fixture_cases`, `BINDING_API = 1`,
and `__version__ = "0.1.0"`. Package import is pure Python and does not import
the extension. The extension is imported only for an explicit native-facing
action. No `_bundle` runtime callback, Python qualification flags, CPU matmul,
NumPy conversion, PyTorch route, or arbitrary model references are present.

`Tensor` freezes metadata and retains explicit byte storage. It accepts exact
built-in bytes/bytearray/memoryview with byte format `B`, `b`, or `c`, rank one,
itemsize one, positive unit stride, contiguous non-indirect storage and exact
extent. Logical shape is an exact two-int tuple; bool/subclasses, nonpositive
dimensions, dimension/extent overflow, unsupported tags/layouts and nonpacked
strides fail before native submission. Layout names are `row_major` and
`column_major`. Native submission revalidates current storage extent and holds
fresh buffer views through the synchronous copying call; the views are then
released. Host input mutation/resize after submission does not retain a facade
export. Native tests must prove the actual C++ copy independently.

The exact six signature restriction and matching session dtype are checked
before dispatch. Each Python operation, native empty handle, weak session link,
expected output extent and pending-registry entry exist before native submit or
model create. Native status failure returns the operation. Exceptional returns
best-effort attach `.operation` and `.session`, but ownership does not depend on
exception attribute allocation. `pending_operations()` returns actual retained
owners in an immutable tuple; only completed explicit close unregisters an
owner. The operation shares only the guard and a weak session reference, so it
can outlive the session.

Status snapshots are frozen. Execution success requires `validation ==
"success"`, zero primary/cleanup and completion. Model success additionally
requires native `success` and terminal outcome. Transient wait/close timeouts
are replaced by subsequent outcomes; terminal completed close status is cached
and remains sticky. Output is independent exact-size little-endian FP32 bytes
or unsigned raw-word tuples. Native output validity remains authoritative.
Matmul output can be read after successful wait; model output requires actual
owner closure and resource/cleanup success. Inspection confirmed that native
`ManagedMlp::advance` does not close its owner: examples must advance, close,
then read output. No implicit close adapter was added.

Model close takes one bounded native close, then calls `model_advance(..., 0)`
to retrieve the stored post-close model status. The native worker confirmed
that this returns the existing result without graph work once closing/closed;
it preserves `closed`, mismatches and cleanup outcomes accurately. If close
status publication is interrupted, the pending owner remains recoverable;
retry `close()` or `advance(0)` to obtain its native outcome. Raw trace and P04
record methods return detached diagnostic dicts and may describe incomplete
or failed work. Record iteration 0/1 must match its specified output poison.

Session information is a read-only mapping with immutable library path tuple.
`memory_info()` returns `(code, free_bytes, used_bytes)` on success and raises
with the native code on failure. Any close request prevents new work; session
close never drains arbitrary operations or advances models. Native session
closure governs whether its own references remain incomplete.

A shared nonblocking owner-aware RLock rejects reentry and concurrent facade
access; ownership inspection lets an interrupted acquire release its lock.
The intended runtime is CPython 3.12. PID checks reject inherited object/native
access after fork. The extension remains responsible for main-interpreter,
free-threaded-build and capsule-destruction safeguards. There is no Python
destructor promising bounded cancellation; native destruction can drain
indefinitely in the creating process.

Context exits perform one bounded close (100,000,000 ns for operations). A
close failure raises `BindingError` retaining the owner and original body
exception as `__cause__`. Successful cleanup preserves a body exception
unchanged. Per root decision, successful voluntary early model close is
allowed without claiming inference success; real terminal inference mismatch
raises even if execution codes alone are zero.

## Public error mapping

| Condition | Public result |
|---|---|
| Wrong Python type, bool, accepted-built-in subclass | `TypeError`, before work |
| Malformed/unsupported shape, dtype, layout, stride, exact extent, negative value | `ValueError`, before work |
| Representational integer/extent overflow | `OverflowError`, before work |
| Timeout outside `0..1_000_000_000` but within uint64 | `ValueError`, before wait |
| Missing/unbound/incompatible extension or bundle opening | `BindingError(kind="bundle")`, native cause retained |
| Native validation failure | Returned status; `raise_for_status()` uses `kind="validation"` |
| Native primary failure | Returned status; `raise_for_status()` uses `kind="native"` |
| Retryable incomplete work | Returned status; `raise_for_status()` uses `kind="incomplete"` |
| Terminal cleanup failure | Sticky returned status; `raise_for_status()` uses `kind="cleanup"` |
| Model numerical/resource mismatch without native code failure | `ModelStatus`; its raise method uses `kind="model"` |
| Inherited process/reentry/invalid owner state | `BindingError` with `process`/`reentrancy`/`state` kind |
| Malformed native result schema or output extent | `BindingError(kind="protocol")` |
| Allocation failure or interrupt during explicit submit/wait/close | Original exception, best-effort owner attachment and retained registry |

`BindingError.status` retains `ExecutionStatus`; `.model_status` separately
preserves model state/terminal flags. `.operation`, `.session` and underlying
exception cause preserve recovery and diagnostics. `ModelStatus.ok` is not a
substitute for the additional native output-publication gate.
