## Interpretation and limits

`job.json` and `preparation.json` are initial receipts and intentionally retain
`native_execution: not_run`. The final model report, bound command logs and
separate completed `final-job.json` establish final execution outcomes. No
original receipt is rewritten to change that interpretation.

The archive is not a binary replay distribution. Native binaries, complete
external submodule/toolchain bodies, system headers and dynamic libraries are
not retained in full. Auditor replay is separate from native re-execution and
requires the qualification commit's main-repository Git objects. Native processor
RTL remains separate from full AFU, vendor `hw_emu`, physical FPGA and silicon
scope. Event timings remain host-clock observations with overlapping intervals.
