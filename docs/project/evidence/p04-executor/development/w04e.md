### Findings

- Exact object field inventories cover the public model, stage and dispatch
  structures. Unknown/missing fields and duplicate JSON keys fail. Integer and
  boolean checks use exact Python types; nonfinite values, floats, negative values
  and values outside unsigned 64-bit range cannot be coerced into observations.
- The application emits `P04_RESULT` only after successful inference, operation
  cleanup, owner cleanup and observed profiling. The consumer independently
  requires all successful observed/compared/closed flags, exact comparison counts,
  zero mismatches, successful status values and complete terminal results.
  A successful asynchronous **submission** may be incomplete; observed completion
  and cleanup must be complete. This distinction matches the actual runtime API.
- Every actual hidden, bridge, native output block and assembled word is checked
  against the frozen case. The native hidden A/B bytes must equal X/W1; output A
  bytes must equal the corresponding actual bridge slice; both output B buffers
  must equal W2. Actual native output blocks must assemble in the declared row
  order. The executor compares actual hidden values before applying the bridge,
  and the bridge consumes those observed values, including negative preactivations.
- The independent 56-byte `<8I3Q` reconstruction matches the established encoder:
  version, byte size, dtype, flags, M/N/K, reserved word and three addresses. Each
  address is aligned, representable for its full extent and disjoint from the
  other operands. Per-stage extents, three writes, one launch and one read match
  the actual managed operator and fixed graph.
- Each of the five events must have a successful observed query and event result.
  Profiles require queued ≤ submit ≤ start ≤ end, enqueue within the enclosing
  submission interval, and predecessor completion before dependent submission.
  Cross-stage and cross-repetition checks agree with executor control flow.
  `Queue::worker_loop` sets submission after dependency waits, publishes the
  profile before completing the event, and uses the same host steady clock.
- Zero-duration intervals remain valid only with the explicit observation/query
  flags and statuses. The verifier does not invent missing measurements. Host
  elapsed fields are recorded separately and are not represented as physical
  accelerator latency or an additive decomposition of wall time.
- Resource counters bracket the native tensor operations while the managed
  owner/module still exists. Their before/after values must agree. Owner cleanup
  is a separate successful-complete observation; these counters are not a second
  memory query after the owner has been closed. Final claims must preserve that
  scope rather than claim a post-device-close allocator measurement.
- Log and per-record byte bounds precede JSON parsing. Deep JSON is rejected,
  output markers and final success framing are unambiguous, and diagnostic failure
  tokens prevent a pass. Serializer array prefixes are bounded before access.

## Additional independent probes

Executed a read-only inline Python probe using:

```sh
PYTHONPATH=ci/project python3 - <<'PY'
import copy
from p04_fixture_adapter import load_cases
from p04_execution_records import verify_output
from test_p04_execution_records import result, output, BINDING, REVISION, FIXTURE_SHA, wire
case = next(c for c in load_cases() if c['id'] == 'fp16-seeded_dense')
row = result(case)
valid = output([row])
checks = 0
def verify(text):
    return verify_output(text, case, 1, BINDING, backend='simx',
                         source_revision=REVISION, fixture_sha256=FIXTURE_SHA)
def reject(text):
    global checks
    try:
        verify(text)
    except ValueError:
        checks += 1
    else:
        raise AssertionError('unexpected acceptance')
reject(valid.replace('"schema_version":1', '"schema_version":1,"\\u0073chema_version":1', 1))
reject(valid.replace('"advance_ns":4000', '"advance_ns":' + '9' * 5000, 1))
reject(valid.replace('"advance_ns":4000', '"advance_ns":-0.0', 1))
reject(valid.replace('"a_bytes":"', '"a_bytes":"\\u0000', 1))
reject(valid.replace('"schema_version":1', '"schema_version":1e0', 1))
reject(valid.replace('"case_id":"fp16-seeded_dense"', '"case_id":"fp16-seeded_dense\\u0000"', 1))
reject('P04_RESULT null\n' + valid)
reject(valid.replace('PASSED!', 'PASSED!\t'))
for i in range(3):
    damaged = copy.deepcopy(row)
    dispatch = damaged['trace']['native'][i]['dispatch']
    dispatch['b_address'] = dispatch['a_address'] + dispatch['a_bytes'] - 4
    dispatch['argument_bytes'] = wire(dispatch)
    reject(output([damaged]))
for i in range(3):
    damaged = copy.deepcopy(row)
    damaged['trace']['native'][i]['dispatch']['event_profiles'][4]['end_ns'] = 1 << 64
    reject(output([damaged]))
assert verify(valid) == [row]
print(f'{checks} independent malformed-record probes rejected; 1 baseline accepted; all records synthetic')
PY
```

Result: **14 malformed-record probes rejected; one synthetic baseline accepted.**
These supplement the unchanged, already tested producer/consumer sources; they
do not execute a compiler, simulator or GPU. Receipt whitespace checks passed.
