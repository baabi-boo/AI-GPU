## Source review

The auditor uses only the Python standard library. It imports no production
validator, fixture producer, model implementation or reference generator.
The frozen fixture is pinned by its complete SHA-256 digest. Reference arrays
are checked against separately calculated values; they do not supply the dot
product results.

| Boundary | Review result |
|---|---|
| Packed operands | Canonical 32-bit hexadecimal words become little-endian bytes; successive 16-bit operands are decoded with the correct FP16 or BF16 exponent/fraction widths. Nonfinite and nonintegral operands are rejected. |
| Matrix layout | X and intermediate activations use row-major indexing; W1 and W2 use `column * k + inner`. Every accumulation prefix is bounded, including prefixes before later cancellation. |
| FP32 encoding | Sign, exponent and significand are formed by integer operations. Exactness/divisibility and overflow checks prevent rounding. Integer zero encodes canonical positive zero. |
| Hidden result | Each actual raw hidden word is compared with the independently encoded dot product before ReLU. The second hidden-word copy must agree. Negative values cannot disappear into ReLU before validation. |
| Bridge and rows | The bridge is reconstructed from validated actual hidden words. Its bytes and packed words must agree, and actual output A bytes must be the corresponding 128-byte bridge slice. Both output blocks and assembled row order are checked. |
| Inventory and repetition | Case IDs are the exact ordered five-case inventory for each format. Variants are unique across packets. Both iterations are strict integers with their distinct expected poisons at model and dispatch levels. |
| Raw/report boundary | Bounded regular nonsymlink files, canonical relative members, descriptor sizes/hashes, duplicate JSON keys, noninteger observation numbers, final success framing, command identity and exact parsed raw/report equality are checked. |
| Aggregation | Counts, comparison totals and tensor traffic are recalculated. Source/profile identities cannot mix. The full matrix is the default requirement; selected scope must be explicit. |
