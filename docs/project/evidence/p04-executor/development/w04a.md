The original finalization path called `stable()`, then called `tool_inventory`
again to record `tools-after.json` without checking this final observation. A
tool change at the latter observation allowed a passing report whose recorded
before/after tool inventories differed.

The durable test
`test_recorded_final_tool_snapshot_is_checked_before_passing` reproduced that
failure: all synthetic model records validated, the sixth tool-inventory
observation changed the compiler hash, and the runner returned `pass`. The
initial isolated regression failed with `AssertionError: 'pass' != 'fail'`.
The finding was sent to `/root`, who updated the runner to retain the exact
`final_tools` observation and require equality with the original inventory.
The same regression now passes and the retained final report records `fail`
for that scenario.
