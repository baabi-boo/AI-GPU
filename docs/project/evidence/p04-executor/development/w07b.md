## Deliverable and independence

Added [audit_numerics.py](../reviews/audit_numerics.py). It uses only Python's
standard library and imports no production validator, fixture adapter or reference
producer. It pins the unchanged fixture digest, decodes packed FP16/BF16 IEEE
operands with integer shifts/divisibility checks, accumulates integer dot products
in the declared row/column layouts, and encodes exact results without host float
arithmetic. Every accumulation prefix must stay inside the original proof bounds.

For each retained model observation, it recomputes the hidden projection from
the actual recorded A/B bytes, checks hidden words before ReLU, recomputes the
bridge from those actual hidden words, and uses each actual bridge slice to
recompute its corresponding output block. It checks actual row-block assembly,
both destination poisons, comparison counts and explicit tensor-byte totals.
Reference arrays are checked against independent mathematics rather than used
as a replacement for intermediate results.

The reader verifies bounded regular nonsymlink files, relative packet members,
duplicate JSON keys, raw log sizes/hashes, strict observation numbers, final
success framing, actual invocation identities, and exact raw/report observation
agreement. Failed, unfinished, dirty-source or development packets cannot supply
passing numerical subsets. Source snapshots and qualification bindings are read
through their retained descriptors. The union must contain exactly the four
unique backend/format variants, five cases per variant and two poison iterations,
unless selected scope is explicitly requested. Selected reports legitimately
have `full_matrix_requested=false`; aggregate completeness is computed afresh.
