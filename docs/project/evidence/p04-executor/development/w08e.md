## Compatible model and evidence level

The A02 criterion explicitly permits an equivalently specified network. The
already accepted, original synthetic batch-16, bias-free 16→8→4 MLP is such a
network: two weight layers, ReLU bridge, fixed shapes/weights/input families,
independent references and exact raw-bit comparisons. A transformer, tokenizer,
trained accuracy or useful language-model capability is not required or
established. The graph has three native matmuls per model run, with actual hidden
outputs feeding the declared host ReLU/exact cast and actual row blocks feeding
assembly. The allowed host work does not turn into a native activation claim.

A02 and A03 each require at least `simulated`. If the complete fresh matrix
includes native processor RTL with proven TFR tensor and STD scalar arithmetic,
`kind=rtl` with `evidence_level=rtl_verified` is compatible for these exact
obligations. Alternatively, a deliberately conservative acceptance may use
`kind=simulation`, `evidence_level=simulated` while identifying the additional
processor-RTL coverage in its scope. The kind and level must agree. Neither
choice establishes AFU integration, vendor `hw_emu`, physical FPGA or silicon.

Keep the P04-T01 manifest and historical A01 packet byte-for-byte. Its
`execution_available=false` and A02/A03 `not_run` fields describe that frozen
source-only work package. New acceptance belongs in separate P04-T02 records;
rewriting historical fields would break the frozen provenance unnecessarily.
