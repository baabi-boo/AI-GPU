**F3, high confidence, reproduced control:** the initial reader accepted an

## Implementation

The new module pins and checks the current trusted generator, both configuration
TOMLs, and the `p02-tfr` profile. Their retained source bodies must match these
trusted local bytes before rendering. The generator identity is:

`ci/gen_config.py`, 60,839 bytes,
SHA-256 `b710a1b80c89d327adf079e61aec9f5d4f950d89342b633b6b00871e50abe165`.

The loader compiles only that verified current generator body, avoiding an
unchecked bytecode cache. It uses the existing parsing, profile, resolution,
and rendering functions. A private module environment supplies `XLEN=64` and a
fixed generator name; approved input reads return the verified trusted bytes
from memory. Rendering does not invoke the generator CLI, a subprocess, a shell,
or a compiler, and cannot open a recorded producer path. The generator's internal
configuration expression evaluator receives only the pinned current TOML inputs;
changed retained expressions are rejected before it is called.

`validate_generated_headers` reproduces and compares all four retained headers:
`sw/VX_config.h`, `hw/VX_config.vh`, `sw/VX_types.h`, and `hw/VX_types.vh`.
`validate_generated_flags` reproduces the complete 273-flag stream for each input
format. The two streams are identical: this generator emits configuration keys,
while `ITYPE`, `OTYPE`, and `KUNROLL` remain application definitions checked by
the separate compiler/build validators.

The nested receipt records exact generator/input/header identities, the selected
profile and XLEN, `native_execution="not_run"`, and
`retained_code_executed=false`. It does not change the original producer packet
or its bindings.

## Scope and remaining limits

The original archive retains four generated configuration/type headers.
`configure` also creates two `vortex_opae` headers, but neither those outputs nor
their source TOML belong to this original retained inventory. Their contents
cannot be reconstructed as original retained evidence and are explicitly outside
this validator's coverage. Byte reproduction establishes consistency with the
trusted inputs; it does not prove that an original compiler consumed the bytes,
authenticate execution, or establish dependency compilation provenance. No
native execution or qualification/acceptance decision was made. No commit or
remote write was performed by this agent.
