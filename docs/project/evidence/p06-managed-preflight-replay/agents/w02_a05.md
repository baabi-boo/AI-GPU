## Interface

`Packet` is a context-managed mutable overlay over ZIP member bytes. Unchanged
members remain in the original ZIP and are read one at a time when a mutated
archive is written. `json(name)` and `report` return detached values;
`edit_json`, `edit_report`, or byte assignment save edits. `write(path)` creates
a new ZIP and returns its SHA-256, refusing an existing destination or the
original path.

`replace_retained` updates matching retained descriptors through the report and
snapshot records. Explicit aliases affect all control JSON. `replace_log`
also updates command and raw-log identities. Neither helper recalculates
semantic observations. Explicit `rehash_snapshots` and `rehash_bindings` support
tests that need consistent source/tool/dependency digests, nested build and
process identities, command arguments, and observation/log qualification IDs.
The external source inventory is never silently changed. `replay()` exposes
the normal reader with pinned original defaults, including the independently
pinned source derivation receipt. Failed-original inventory and derivation
constants are separately pinned to its earlier source revision.
