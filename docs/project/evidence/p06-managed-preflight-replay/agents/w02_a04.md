# Wave 2 assignment 4 — complete application command replay

## Finding and implementation

The original `validate_host_build()` accepts an application log containing only
the final host compile/link line. Added the pure
`ci/project/p06_managed_preflight_application_build.py` validator and integrated
its call after independent compiler-record validation in
`p06_managed_preflight_replay_build.py`. The original producer binding shape is
unchanged; the separate `self.application_build` receipt describes replay.

The new closed grammar checks all 30 original commands per format: the host
dependency scan; two recursive Make commands; fourteen RISC-V GCC compilations;
two archives and two archive dumps; five kernel Clang commands; VXBIN conversion;
kernel dump; runtime-stub compilation/link; and final host compilation/link.
It checks selected tool paths, exact flags and ABI, source/object mappings,
ordered archive members, linker inputs/outputs, and dependency order. Independent
parallel build branches may interleave. Extra commands, including unrelated
shell commands, fail validation.

Eight retained recipe/script bodies are checked through the independently
verified `source_body` callback against reviewed SHA-256 identities. Unsupported
recipe drift fails closed. Reconstruction uses the separately checked kernel
and host compiler records and selected source/build/tool roots. No retained
shell command, startup `$(...)`, source code, or binary is evaluated or executed;
producer paths remain lexical data. Spaces and tabs normalize; quotes, shell
punctuation, and command boundaries remain significant. Blank LF lines and a
missing final LF are accepted; control separators and line continuations fail.
