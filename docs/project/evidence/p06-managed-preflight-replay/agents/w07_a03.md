## Resource and structural boundaries

The [pinned archive helper](../../p05-torch/reviews/archive_reader.py) checks the
external digest before ZIP parsing and rehashes the original at close. It
requires a bounded regular file at an absolute canonical path without symlink
components, and repeatedly checks the open descriptor and named file identity.

| Boundary | Enforced limit or rule |
| --- | --- |
| Original ZIP / central directory | 256 MiB / 32 MiB; directory extent checked before member-list allocation |
| Members / expanded total | 20,000 entries / 1 GiB |
| Repeated reads | 100,000 attempts and 2 GiB cumulative charged bytes |
| Individual member / JSON | 256 MiB / 16 MiB; JSON depth 64 and 300,000 visited values |
| Managed payloads | 64 MiB per retained body and 256 MiB unique-body total |
| External inventory / derivation | 8 MiB / 16 MiB, each through bounded no-follow access |

Read attempts and advertised expansion are charged before decompression, so
CRC failures cannot reset the budget. Actual returned bytes are also counted.
The admitted format rejects trailing bytes, archive comments, unsupported
ZIP64/multidisk forms, encryption, and unsupported compression. Member checks
reject absolute/traversing/noncanonical names, hidden NUL suffixes, duplicates,
file/directory collisions, files shadowing parents, and symlink/special entries.
No extraction path is used.

## Complete retained-data closure

The [managed reader](../../../../../ci/project/p06_managed_preflight_replay.py)
requires every externally expected source body, then verifies its descriptor
and bytes; missing source members cannot be replaced by metadata. Exact
dependency and per-format payload inventories similarly require all 17 bodies.
Raw-log order, repeated descriptor consistency, and the complete retained-file
inventory reconcile with semantically used members. Missing or extra managed
files fail the final file-set equality.

The [hosted mixin](../../../../../ci/project/p06_managed_preflight_replay_hosted.py)
also compares the seven outer files and managed subtree against the enclosing
view, then compares that view against the entire archive. A nested prefix
therefore cannot hide an unrelated file elsewhere in the ZIP. Empty directory
entries are structural metadata; these checks close data files, not every
possible ZIP metadata byte.

The source-input loaders independently check caller-supplied digests before
strict JSON interpretation and refuse links/nonregular files through
[descriptor-relative access](../../../../../ci/project/baseline_packet_io.py).
Recorded producer paths remain syntactic data. The current trusted runtime,
repository modules and explicit caller-selected inputs remain prerequisites;
the checks do not protect against arbitrary corruption of the running Python
host. Direct compilation of the pinned current archive helper is distinct from
executing retained code.
