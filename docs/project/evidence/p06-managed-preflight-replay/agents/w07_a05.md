## Disposition

The repair closes the reproduced [nested-tree substitution finding](w07_a02.md).
No remaining F1–F3 defect was identified in the reviewed change.

The [exporter](../../../../../ci/project/p06_managed_preflight_source_export.py)
now reconstructs the complete admitted tree from its bounded flat listing and
requires the resulting root object ID to equal the selected root. Every leaf's
name, mode and raw object ID participates. Synthesized directories use raw mode
`40000`; sorting compares directory names with a trailing slash, while regular,
executable, symlink and Gitlink leaves retain their correct modes and ordering.
The same blob or subtree object may occur at different paths.

File/directory prefix collisions reject in either insertion order. Implicit
directories count toward the existing 50,000-entry bound. The parser's prior
64-component path limit bounds recursion before reconstruction starts. Omitted
empty trees fail closed with an explicit unsupported-tree diagnostic. The
reconstruction adds no Git command, source read, output field, or acceptance
claim. Selected blob bodies still undergo their separate exact hash check.

This binds the admitted listing to its caller-selected Git root identity. It
does not authenticate remote origin, establish dependency compilation, or defend
against an arbitrarily compromised current runtime. Existing limitations remain.
