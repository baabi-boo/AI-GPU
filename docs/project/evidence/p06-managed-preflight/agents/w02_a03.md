# Wave 2 / assignment 3 — checked production build validation

Implemented only `ci/project/p06_managed_preflight_build.py`. No historical
validator, production source, fixture, tolerance or baseline was changed.

## Interfaces for integration

- `validate_records(runtime, backend, application, *, driver='simx', fmt,
  source, build, jobs)` returns four role rows in historical order. Each retains
  the original checked line in `original_record`, its original `sha256` and
  original `macro_flags`. `projection_sha256`/`projection_removed` identify the
  validated narrow projection. The configuration includes
  `SIMX_CHECKED_COUNTERS='1'`.
- The sole compiler-macro extension is exactly one direct
  `-DSIMX_CHECKED_COUNTERS=1`. Missing, zero, repeated, forwarded, undefining or
  additional timing/worker macros reject. The only extra host include is
  `-I<source>/sw/runtime/common`, immediately after `-I<source>/sw/runtime/ai`.
  The remaining records pass the unchanged exact warm validator.
- `host_link_flags(build)` pins four old observer wraps, the MPM query wrap,
  `-L<build>/sw/runtime`, `-lvortex`, `-lvortex-simx`, in that order.
  The host app uses libc's `dl_iterate_phdr`; no extra loader library is admitted.
- `validate_effective_header(text, expected, *, driver='simx', role)` requires
  the exact original `#define SIMX_CHECKED_COUNTERS 1` line. `expected` must
  include that same guard; after its narrow removal, the historical effective
  header validator checks the complete frozen hardware configuration. Use the
  old validator directly for unguarded generated-header probes.
- `validate_backend_linker(text, *, build)` pins the exact production link
  plus the five read-only Processor wraps. `BACKEND_LINK_STAMP` is
  `sw/runtime/preflight_backend_link.stamp`. Literal quoted `$ORIGIN` is retained;
  unquoted shell expansion is rejected.
- `validate_build_commands(text, runtime, backend, backend_linker, *, source,
  build, compiler, make, fmt, source_files)` checks exactly 43 fresh production
  model translation units, their one-to-one object and dependency-file paths,
  the exact model link and its reused dependency inputs, and the backend's
  three production sources plus `hooks.cpp`. Extra diagnostic objects,
  substituted/accessor sources, missing compiles, foreign flags, repeated links
  and other target paths fail. It treats records as data, without reopening
  recorded producer paths. `MODEL_SOURCES`, `BACKEND_SOURCES`, `APP_SOURCES`
  and `REQUIRED_SOURCE_FILES` expose the versioned inventories.

## Build invocation requirements

Invoke the generated `backend.mk` from `<build>/sw/runtime/simx` with
`DESTDIR=<build>/sw/runtime`, `CXX=<pinned absolute g++ path>`, `THREADS=1`,
`-j2`, checked CONFIGS and `PERF=1`. An explicit CXX command-line assignment also
prevents the production SimX Makefile from prepending a discovered `ccache`.
Do not rely on the backend's default `CURDIR/..` destination: the validator
requires canonical recorded paths. Both policies must use the same final
frozen per-format artifacts, verified by the runner before and after execution.

The validator expects the nested model make line to use the pinned absolute
make path, `DESTDIR=<runtime>`, `-C <build>/sim/simx`, and the exact model-library
target. Real build integration must inspect any difference; do not loosen the
accepted command inventory speculatively.

configuration/stamp generation and native host preprocessing, with backend and
kernel compiler guards ensuring no native compile occurred. FP16 and BF16 both
passed four checked compiler-role records and four checked effective headers.
Absent/disabled/repeated guards and a parallel-worker macro were rejected.

diagnostic socket substitution and unquoted loader-path variants failed.
Receipt: `w02_a03-smoke.json` in this work directory. Python AST also passed.

These are generated-stamp and synthetic-record tests, not native build or GPU
execution evidence. Native full source/link/dependency validation remains the
runner and independent review's obligation. The parsed result explicitly keeps
dependency compilation provenance unverified and qualification false; exact
reused library names and hashes do not prove their compilation or loaded bytes.
