## Runner integration

Coordinated with assignment 05. Final invocation:

```sh
python3 ci/project/p06_managed_preflight_execute.py run \
  --source-dir "$PWD" \
  --tools-dir "$P06_PREFLIGHT_ROOT/tools" \
  --work-dir "$P06_PREFLIGHT_ROOT/work" \
  --output-dir "$P06_PREFLIGHT_ROOT/evidence/managed-preflight" \
  --expected-revision "$GITHUB_SHA" \
  --jobs 2 --timeout-seconds 1800 --run-timeout-seconds 180
```

`--host-bin` is intentionally omitted: the runner then retains its executing pinned interpreter directory at the beginning of the controlled PATH. Supplying `/usr/bin` would select the hosted OS Python instead. The live runner supports the exact options above. Its reported narrow native success key is `native_preflight_passed`; no warm readiness or acceptance claim is implied.
