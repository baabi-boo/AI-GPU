## Delivered

Created only these repository files:

- `tests/regression/ai_counter_preflight/main.cpp`
- `tests/regression/ai_counter_preflight/Makefile`

The application includes the unchanged warm caller with its entry point renamed,
then reuses its exact options parser, original observer, runtime sources, kernel,
fixtures, numerical checks, and warm records. The outer entry point permits only
the contract's pair-zero warm-up identity. It emits one
`P06_MANAGED_COUNTER_WITNESS` JSON trailer after successful old warm execution
and complete disposal. Any missing or inconsistent hook, ownership, loaded-object,
or retirement observation makes the process fail, including failures found after
the old caller printed `PASSED`.

The public MPM wrapper observes four ordered snapshots of exactly 33 available
queries each, checks each actual low/high reply against the returned public
aggregate, and retains the 264 raw replies. It records actual read-only Device
references, registered queue/buffer counts, native processor state, and terminal
enabled command-processor retirement before and after the last snapshot. The
terminal snapshot must retire precisely 66 read commands. Raw zero head storage
is explicitly labeled `not-published`; retirement is established from enabled
idle status and the retired sequence. The raw tail pair is not described as a
published hardware head.

The successful trailer retains the actual construction and disposal observations
and exactly five loaded library paths observed through `dl_iterate_phdr`. Those
paths are required to remain identical across the managed execution. All seven
qualification/readiness/acceptance flags remain false, and the three frozen
unresolved obligations remain explicit. No seeded diagnostic access or simulator
headers are included by the host application.

## Build integration

The Makefile adds AI then runtime-common include directories before common.mk,
keeps the original four linker wrappers, adds the public MPM wrapper, and links
`-lvortex -lvortex-simx` in that order. `dl_iterate_phdr` requires no added `-ldl`.
These exact flags were coordinated with the independent compiler-record agent.
The backend shared object is not added to `$^` or introduced as a host prerequisite.
The runner must first build the wrapped backend through its dedicated backend.mk,
then use this application's `make all`; `all` does not silently rebuild the
ordinary backend.
