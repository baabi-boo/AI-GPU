## Fix review

Reviewed every final changed hunk in `p06_managed_preflight_execute.py`:

1. The common Make argv retains the exact host C++ compiler and stops exporting
   host `CC` to the application build.
2. The backend invocation adds host `CC` explicitly at its original position,
   preserving the previously successful backend command selection.
3. The application retains `-j2` and adds `--output-sync=target` before `all`.
   This keeps parallel recursive Make output grouped for original-log parsing.
   It does not reduce build jobs or alter the model's `THREADS=1` selection.
4. Comments accurately describe kernel compiler inheritance and original-log
   preservation. The kernel Makefile continues selecting its configured
   RISC-V GCC; the application kernel still uses configured Vortex Clang++.

The first unsynchronized parallel dry-run produced a missing prefix-selected
RISC-V compile line together with RV64 flags in a prefix-selected host G++ line.
That observation is consistent with interleaved long compiler echoes. Its raw
output was in a temporary directory already removed, so I do not claim a
