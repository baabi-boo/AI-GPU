## Stable report and retained bytes

`report.json` has schema_version=1 and the dedicated contract_id. It contains commands, variants, processes, failures, stability_checks, budget, resources_before/after, expected_counts, completed_counts, source/tool/dependency before/after snapshot identities, raw_logs, and retained_files. Every command preserves original argv, cwd, allowlisted environment, bounded-process receipt, and raw log identity. `native_execution` has exactly three producer states: `not_run` means no observed native start and no unresolved native attempt; `run` means at least one reliable process_started=true receipt; `unknown` means the native supervisor was attempted but no conclusive start receipt is available. Unknown is checkpointed before invoking supervision; an explicit budget-refused process_started=false restores the prior state, and a previously observed native start remains run. Supervisor exceptions retain available partial raw log bytes and their identity without inventing cleanup, timing, or resource receipts. Early failures retain a finished report and zero native completion counts.

Per variant: id/backend/format/build_dir, original compiler_records, model_build_records, host_build_records, effective_headers, generated_identity, artifacts_before/after, expected_loaded_libraries, build_binding_sha256, binding snapshot identity, retained_builds, and retained_binary_payloads. Per process: immutable plan fields, command_id, execution_binding_sha256, build_binding_sha256, binding snapshot identity, raw log path, process_duration_seconds, observation, and retained_observation.

Retained source bytes are under `artifacts/source/`. Original generated headers, stamps, Makefiles and probe bodies are under `artifacts/simx-FORMAT/{configured,backend,frozen,failure}/` as reached. Actual app, ELF/kernel image, kernel runtime archive, runtime stub, backend, and model payloads are under `artifacts/simx-FORMAT/binaries/`. The three selected actual dependency payloads (softfloat archive, libramulator.so, libramulator-vortex.so) are copied once under `artifacts/dependencies/`. Each retained binary payload must be nonempty and at most 64 MiB, with 256 MiB combined payload cap. Replay should use exact inventories, rehash these inert files, and never execute retained payloads or expand arbitrary globs.

The exact selected-library map contains only libvortex.so, libvortex-simx.so, libsimx.so, libramulator.so, and libramulator-vortex.so at canonical actual paths. Symlink path aliases are rejected.

All qualification/readiness/warm execution/acceptance claims remain hard false even when native_preflight_passed is true. Dependency source-to-binary compilation provenance and complete all-40/pending-balance lifetime proof remain unresolved. This producer does not promote the fixed excluded inner observations into a performance experiment.
