## Result

contract and 30 focused host tests. The module validates exact sorted source

complete independent descriptors exactly. No dependency-compilation or Git-tree
provenance claim is made. Arbitrary roots, evidence paths, hidden extensions and
binary/archive extensions are rejected.

## API

- `required_source_names()` checks and returns the fixed minimum.
- `validate_source_inventory(document, *, expected_revision)` purely validates
  and copies the complete manifest.
- `decode_source_inventory(contents, *, expected_sha256, expected_revision)`
  verifies exact original bytes before strict duplicate-key/depth/token-aware JSON.
- `load_source_inventory(path, *, expected_sha256, expected_revision)` uses the
  existing bounded no-follow `PacketReader`, then rechecks file/directory identity.
- `validate_retained_sources(actual, expected, *, expected_revision)` requires
  exact complete descriptor equality. The caller must separately rehash actual
  retained archive bodies; descriptor matching cannot substitute for that.

`producer_contract_id` is always exactly `p06-managed-counter-preflight-v1`.
There is no fallback when an explicit expectation is malformed or mismatched.
