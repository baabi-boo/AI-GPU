```python

               expected_receipt_sha256, expected_native_report_sha256,
               expected_source_manifest_sha256, prefix="")
```

The CLI requires five independent intake expectations:

```text
python3 ci/project/p06_dependency_native_replay.py \
  --archive ORIGINAL.zip --sha256 ORIGINAL_ZIP_SHA256 \
  --source-revision EXPECTED_COMMIT \
  --dependency-receipt-sha256 DEPENDENCY_REPORT_SHA256 \
  --native-report-sha256 NATIVE_REPORT_SHA256 \
  --source-manifest-sha256 NATIVE_SOURCE_BEFORE_SHA256 \
  --output NEW_REPLAY_RESULT.json
```

`--source-manifest-sha256` means the exact byte digest of
`native-lifetime/snapshots/source-before.json`. It is separate from the
dependency receipt's complete pinned Git source manifest. The former binds the
native retained source inventory but does not independently prove superproject
Git object membership. `--prefix` optionally names a literal hosted root inside
the ZIP; the selected native and dependency subdirectories remain fixed.
Output uses exclusive creation.
