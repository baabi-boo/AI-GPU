## Positive fixtures and rejection reachability

`OuterRecipeOptionControls` reuses the existing outer-recipe fixture. It has
real selected-tool identities and real retained launcher bytes, but its outer
supervision metadata and logs are synthetic test data. Every test first passes
that unchanged positive through `_verify_outer_commands`. The tests therefore
establish exact recipe-option rejection, not actual SoftFloat compilation or
complete native execution.

The controls change related representations together. SoftFloat option changes
update both `SOFTFLOAT_OPTS` and `COMPILE_C`; specialization changes update both
`SPECIALIZE_TYPE` and the selected include directory. CMake changes update both
`cmake_configuration` and the corresponding configure argument. The Make helper
checks that its initial rendering exactly matches the original, preserving the
automatic output `$@` and original quoting. Each negative asserts its specific
semantic rejection message.

`ActualGeneratedOptionControls` executes the existing tiny host CMake fixture
using the selected compiler/archiver/indexer and recorder. It produces seven
actual records: three compiles, one archive, one index, and two shared links.
Every test first passes all seven records through `_validate_record` and passes
their generated CMake data through `_verify_generated_build`. It then reviews
retained bytes as inert dictionary data. This is a tiny host fixture, not the
406-translation-unit dependency build and not a SIMX observation.

Generated-file mutations update the retained SHA-256 and size descriptors before
review, so a stale descriptor cannot hide the intended semantic rejection.
Record-argument mutations update the requested arguments, actual arguments and
observed child arguments together. The archive-mode mutation explicitly passes
individual receipt consistency before the generated-recipe join rejects it.

| Control | Changed evidence | Required real rejection |
| --- | --- | --- |
| SoftFloat TLS replacement and removal | Both option declaration and compile recipe | `SoftFloat outer recipe or worker bound differs` |
| Round-odd and either fast-division option removal | Both option declaration and compile recipe | Same exact SoftFloat recipe gate |
| Wrong specialization | Make selection and include root together | Same exact SoftFloat recipe gate |
| SoftFloat compiler, archiver or archive-mode replacement | Selected recorder tool or archive mode inside Make recipe | Same exact SoftFloat recipe gate |
| External fmt, header-only external fmt, or standard formatting | CMake settings and configure arguments together | `CMake source/configuration selection changed` |
| Build type, language standard/extensions, PIC, selected shared-library modes, or spdlog TLS | CMake settings and configure arguments together | Same source/configuration gate |
| Fetches reenabled | Both disconnected settings tested individually with matching argv | Same source/configuration gate |
| Compiler, Make, or shared-link map substitution | CMake settings and configure arguments together | `CMake compiler or map selection differs` |
| Direct archiver/indexer bypass | CMake settings and configure arguments together | `CMake archive tool wrapper differs` |
| Alternate local spdlog source | CMake setting and configure argument together | `CMake selected different fetched source inputs` |
| Extension compiler/linker or map substitution | Exact extension command | `extension outer recipe differs` |
| Release compiler flags or static/shared linker flags | Actual generated cache, descriptor rehashed | `generated CMake cache changes the selected build environment` |
| Archive/index wrapper bypass | Actual generated link recipe, descriptor rehashed | `observed archive/index/link differs from its generated CMake target recipe` |
| Archive-mode substitution | Self-consistent actual/requested/child argv; individual receipt passes first | Same generated-recipe join |
| Selected executable substitution | Self-consistent selected path and child executable | `tool receipt selected a different executable` |
| Map replacement, removal, or duplication | Self-consistent actual/requested/child argv | `link map is not the actual link output` |
