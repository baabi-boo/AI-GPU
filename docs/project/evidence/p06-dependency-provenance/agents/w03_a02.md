## Findings and changes

### Fixed: complete pinned tree rejected a literal documentation name

**F2, high confidence, static proof plus actual execution.** The real pinned
yaml-cpp tree includes `docs/How-To-Parse-A-Document-(Old-API).md`. The new
dependency relative-path grammar rejected its literal parentheses. Scanning all
five complete pinned trees established that these two characters, in this one
basename, were the only additional punctuation required.

Added literal `(` and `)` to the new dependency relative-path grammar, retaining
the existing bounded components, traversal, control-character, `.git`, symlink,
hardlink and special-file rejection. Command-root grammar remains unchanged.
The historical `GitObjects.blob()` reader also rejected this name through its
old selected-source grammar. Added a dependency-only subclass that uses the new
inert name validation while preserving the existing Git object size, SHA-1,
shared byte budget and command budget checks. The historical exporter was not
edited; a compatibility test proves that its original grammar still rejects
this path while the new complete-tree materializer accepts it.

The parent was notified that new builder/admission file identity guards and the
receipt reader also need to accommodate this exact pinned inert filename. Those
other modules are outside this assignment's ownership.

### Fixed: SoftFloat logical object lists counted a continuation as an object

**F2, high confidence, actual execution.** Each pinned `OBJS_*` list ends with a
backslash followed by an empty line. The section regex stopped before that
newline, leaving a standalone trailing backslash. The attempted graph therefore
reported 32/21/259 tokens instead of the reviewed 31/20/258 object counts.

The parser now includes the section delimiter's first newline when processing
continuations. Counts, object order, specialization and selected source names
are unchanged. Small parser helpers make this exact failure and the rejection
of ambiguous declarations, variable expansion, shell text, traversal, changed
targets and changed populations directly testable. The graph was rerun against
the real pinned source bytes after the refactor and produces the same 406-unit
plan digest.

### Fixed: preparation could admit ignored submodule build inputs

**F2, high confidence, static proof and admission control.** The parent checkout
status and selected product checks did not establish that initialized dependency
worktrees lacked other ignored files, such as an existing `CMakeCache.txt`.
Preparation now requires each initialized SoftFloat/Ramulator worktree to have
an empty porcelain status including all untracked and ignored paths. This is
checked before relocating the toolchain or acquiring fetched sources.

### Fixed: known workspace collisions were detected after tool relocation

**F1, high confidence, static proof and filesystem control.** Existing acquisition
or acquisition-log directories were checked after moving the toolchain out of
the checkout. Their freshness checks now precede that move. An intentionally
occupied workspace therefore retains the original toolchain location and emits
a blocked preparation receipt.

### Fixed: interrupted preparation lacked a useful retained reason

**F2, high confidence, injected failure control.** `KeyboardInterrupt` was not
handled by the preparation failure path, so the final save could retain a
blocked report without a reason. Interruptions now produce the explicit reason
`interrupted`, preserve already completed command records, and cannot produce a
passing outcome. An exit-zero acquisition result with a non-null monitor reason
is also rejected. No resource limit or success gate was reduced.
