## Reviewed implementation boundaries

The full `verify_document()` entry point establishes canonical, disjoint
measurement-source and owned-workspace roots before the new helpers are used.
The fixed fresh source/build roots lie within that workspace. Individual tool
records already validate the canonical declared and resolved input paths,
retained byte identities, matching before/after inputs, and compiler dependency
observations. The new source/header check therefore operates on validated
lexical identities and does not open producer paths.

`_verify_compile_inputs()` retains the existing requirement for a fresh-source
input to be a canonical member of the immutable source inventory with matching
size and digest. Other inputs are rejected if either their declared or resolved
path enters the measurement source or owned workspace. This covers additional
build/evidence inputs and external spellings that resolve into project inputs.
Inputs outside both project roots retain their existing limited system-input
treatment. The change does not claim a complete compiler or system-header
provenance chain, and it adds no generated-header exception.

`_verify_link_map()` retains the actual map parser, archive-member validation,
required archives/libraries, and exactly-once requirement for every observed
direct input. It then compares the complete project-root `LOAD` multiset with
the expected direct inputs. The parser normalizes relative path spellings
before that comparison, so the comparison uses the same canonical names as the
validated compiler/archive graph. The new helper is called only after the
surrounding code has checked the link's object/archive identities, completed
prerequisites and fixed map-output location.

The compiler-support exception is restricted to the exact paths in the
separately admitted external-archive inventory. Before either shared-library
map is checked, the full entry point validates the allowed archive names,
selected compiler's resolution command and output, retained archive bytes and
parsed member inventory. The helper also requires those paths to exist in its
admitted archive mapping. There is no blanket `/usr` exception and no assumption
that a tool installation must live outside the workspace. Repeated GNU map
loads of an admitted compiler-support archive retain their previous treatment;
the exactly-once checks still apply to the selected direct project inputs.

The new helpers add pure path/set comparisons. They do not change the receipt
schema, selected source graph, command recipes, byte bounds, resource ceilings,
success conditions, or the seven false qualification/acceptance fields.
