## Findings fixed

1. The reader checked the CMake configure/build command but did not constrain
   the SoftFloat and extension outer commands. It now checks their complete
   argument vectors, selected recorder, configuration digest, specialization,
   compiler flags, canonical outputs and two-job Make bound.
2. CMake compiler/linker launchers and archive wrappers were self-selected by
   retained metadata. Their exact command vectors and retained shell bodies are
   now derived independently; retained wrappers are compared as inert bytes.
3. Generated CMake cache, flags and link recipes were retained without being
   reconciled. The reader now binds all explicit configure settings, selected
   build environment, each observed CMake compile to its generated target flags,
   and each selected archive/index/shared-link execution to its generated
   `link.txt` command and working directory.
4. An actual tiny CMake run selected `/usr/bin/gmake` automatically while the
   producer tool inventory named `/usr/bin/make`. Root added explicit
   `CMAKE_MAKE_PROGRAM=tools["make"]["path"]` to the builder after this finding.
   The reader checks both the configure selection and generated cache value.
5. A retained descriptor could be read without first being a member of the
   declared retained inventory. Every subsequent read now passes through the
   exact bounded inventory and its digest. Tool/helper inventories, source/build
   roots, output-root disjointness, outer command fields, resource observations,
   compiler PATH and deterministic receipt ordering are checked explicitly.
6. Archive indexing arguments and shared-link prerequisite timing lacked their
   exact joins. The reader now requires the selected one-argument indexing
   recipe, canonical archive/product/map outputs, completed object/archive/link
   prerequisites and exactly one map LOAD for each selected direct input.
7. Final generated source-root and stability summaries were trusted. They are
   now reconstructed from successful retained tool outputs and checked at every
   required before/after boundary, through staging and finalization.
8. The full pinned yaml-cpp tree contains the literal documentation filename
   `How-To-Parse-A-Document-(Old-API).md`. The retained-relative-path grammar now
   admits literal parentheses while retaining traversal, separator and shell
   punctuation rejection. Executable/argument paths retain their existing
   strict grammar. This coordinates with W03-A02's immutable-source fix.

All seven qualification, warm and acceptance flags remain false. The selected
contract identity, source locks and execution/resource limits were unchanged.
