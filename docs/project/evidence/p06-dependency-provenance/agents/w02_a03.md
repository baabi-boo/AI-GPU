# W02-A03 — inert archive and linker-map implementation

## Scope and result

Implemented `ci/project/p06_dependency_binary.py` and its separate host tests.
Only those two implementation files and this report were written. The selected
starting source remains published `832ae98178d7ce9022a13f1a69d9082f909c9e0d`;
the test execution below used the explicitly uncommitted new reader/test files.
No production dependency build, native managed execution, acceptance decision,
commit or remote update was performed.

The reader uses only supplied bytes/text and lexical `PurePosixPath` processing.
It never opens a producer path, invokes an archiver/linker, extracts members or
executes retained code.

## Public interfaces

| Function | Input and result |
| --- | --- |
| `parse_archive(data)` | Bounded immutable `bytes`; returns archive SHA-256/size, exact ordered member descriptors, symbol count and long-name-table presence |
| `validate_archive(data, expected_members)` | Exact ordered list of `{name, sha256, size_bytes}` compiler-output descriptors; rejects any member/order/byte mismatch |
| `parse_link_map(text, *, cwd)` | GNU ld map and recorded canonical absolute working directory; returns selected members, input-section members and separate normalized `LOAD` paths |
| `validate_link_map(text, *, cwd, archives, required_archives=None, required_loads=())` | Exact allowed archive paths mapped to verified member descriptors; requires selected membership and unique required static/dynamic loads |

`required_archives` defaults to every supplied archive. Explicitly inventoried
toolchain/system archives can be included in `archives` while the required set
names the selected dependency arcs. There is no blanket `/usr` or similar
prefix exemption. Relative map paths are resolved lexically against the supplied
working directory, with root escape and unsafe syntax rejected.

## Enforced binary boundary

The archive parser supports ordinary GNU archives, 32-bit and 64-bit symbol
tables, GNU long-name tables and offset references. It checks exact header and
padding bytes, canonical numeric fields, bounded bodies/counts, normal metadata
order, symbol offsets into actual object headers, safe names, exact long-name
entry boundaries and absence of unused entries. It rejects thin archives,
duplicate resolved names, unsupported BSD formats, traversal names, empty
objects, truncation and unexpected trailing bytes. Hashing the substituted
archive again cannot repair its mismatch with observed compiler outputs.

The map parser recognizes the actual GNU archive-inclusion section, including
wrapped long rows and archive-member referrers. `LOAD archive.a` alone supplies
no member-selection evidence. Archive selections must equal the archived object
set seen in GNU input-section records, preventing omission of the inclusion
heading or a member row while retaining favorable section/load records.
Selected members must occur in the supplied verified archive inventory. Whole-
archive grammar is outside this reviewed route and rejects explicitly.

Map text, line counts, line lengths, member counts and archive bytes are bounded.
Required expectations use exact field/type checks, including rejection of bool
values in integer descriptor fields. The reusable reader returns evidence
consistency only; actual trusted tool execution and source/product/loader joins
remain the surrounding producer and original-review obligations.

confusing/duplicate loads, unknown members, missing archive sections, missing

bounds. A read/execute guard patches both file-opening and subprocess APIs while
the reader validates favorable retained data; no prohibited operation occurs.
