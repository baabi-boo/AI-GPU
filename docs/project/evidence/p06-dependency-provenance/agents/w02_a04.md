`ci/project/test_p06_dependency_build.py`. The producer consumes the separate
fresh-source preparation report, creates independent source/build roots, and
retains the complete locked source trees before compiler execution. It uses the

- SoftFloat uses the upstream Makefile with explicit recorder-backed
  `COMPILE_C` and `MAKELIB` overrides, the fixed RISC-V specialization, all
  reviewed options, ordered `ar crs`, and two jobs.

  yaml-cpp/spdlog/argparse trees. Compiler and shared-link launchers record the
  actual children; explicit archiver/indexer shims record static archives.
  Only the `ramulator` target is built, with two jobs.
- The extension uses the reviewed GDDR6 C++20/O3/NDEBUG/PIC recipe, complete
  dependency observations including system include roots, and an explicit
  shared-link map.

The producer reconciles the actual compilation source population with all 406
selected plan entries, validates the three static archives against recorded
object bytes, and validates both selected dependency link maps. Any selected
compiler support archive is retained separately and tied to an observed
compiler `-print-file-name` resolution. It stages only the three verified
products and the complete fetched yaml-cpp, spdlog and argparse source trees at
their canonical measurement paths. Existing destinations are rejected.

## Evidence and failure behavior

plans, frozen project helpers, selected tool identities, recorder configuration,
bounded outer commands and logs, actual per-tool execution receipts, source and
object payloads, generated CMake inputs and compile database, archive members,
maps, products, and exact staged-file identities. Repeated checks detect source,
helper, tool and staged-product drift. The exact empty regular recorder lock is
permitted; unexpected receipt-directory entries are rejected.

qualification, warm and acceptance claims remain false.
