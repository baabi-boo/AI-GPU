## Finding W03-A01-F2-01

**Severity F2; confidence high; evidence: executed host reproduction and static
proof.** `_link_target()` used `posixpath.normpath()` before
`_resolved_member()` followed symlink components. POSIX resolution follows a
symlink before interpreting later parent components. The two interpretations can
select different files, permit an escaping link, or hide a cycle.

A tiny fixture adds these entries:

```
libcrt64/outside          regular internal decoy
libcrt64/dir/alias        symlink -> ..
libcrt64/escape           symlink -> dir/alias/../../outside
```

The initial producer and inert reader both returned `pass`, while the actual
`escape` link resolved outside `tools_root` and read a controlled external
sentinel. The lexical resolver instead selected `libcrt64/outside`.
`tarfile.data_filter()` did not catch the mismatch because link creation is
deferred until after all archives have been scanned. The selected-tool checks
do not inspect every unselected support link.

A second fixture demonstrates a hidden cycle by targeting
`dir/alias/../libcrt64/loop` while providing the lexical decoy
`libcrt64/dir/libcrt64/loop`. A valid internal target that traverses an alias
and then `..` is incorrectly rejected by the initial implementation.

The fixed archive hashes restrict live production intake to the reviewed
bundle. This finding does **not** establish an escaping link in that bundle.
It does establish that the new extractor and metadata validator disagree with
real filesystem link semantics and do not enforce their declared containment
invariant for the admitted member/link types.

### Required repair

Resolve path components in order, expanding each symbolic link before applying
later `..` segments. Preserve the same-component requirement throughout actual
resolution, bounded link expansion, and cycle rejection. After materialization,
check every link against the semantic result and containment requirement, not
only the eleven selected tool/library entry points. Keep the inert reader free
of producer-path filesystem reads.

Root accepted this finding and owns the production repair. Independent inspection
of repaired source SHA-256
`7f7f55ebdcbe1a27c620ec83fe4b3c47abdca2cd453431ebb315ed97aeed6709`
confirms component-by-component expansion before later parent segments, the
100-expansion bound, same-component containment, and a final real resolution
check of every materialized link. The original five independent controls and
the 20 author controls pass together: **25 tests in 0.177 seconds**. Output is
retained at `/workspace/scratch/279b6658611e/validation/w03_a01-after-fix.log`.
This closes W03-A01-F2-01 for the reviewed repaired revision.
