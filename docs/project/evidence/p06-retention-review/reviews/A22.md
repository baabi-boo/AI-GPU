## Missing check and focused result

The concrete gap concerned **successful** use after mutating metadata snapshots.
A shallow manifest snapshot could share its nested directory/file collections;
a shared entry snapshot could redirect offsets, sizes or digests. The former
negative test did not positively demonstrate that these mutations leave a later
valid copy and report intact. The implementation already satisfies the contract.

The standalone producer-backed probe created two distinct small files, mutated
nested manifest fields/lists and entry directory/offset/size/hash values, deleted
one exposed entry and added a phantom entry. Fresh snapshots, original manifest
bytes and reports stayed equal; both original files copied successfully; normal
context exit succeeded. Source hashes were stable across this probe. It did not
reuse the reader's unit-test fixture or any private reader implementation helper.
