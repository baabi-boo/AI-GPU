## Implemented

The reader opens canonical absolute archive/optional summary paths by walking
every ancestor with directory/no-follow descriptors. Only bounded single-link
regular files are admitted. Complete validation precedes context entry and any
caller restoration. The archive stays open until context exit.

The first manifest header is parsed only for its bounded canonical octal size,
then compared against a freshly constructed producer-format header. The
manifest rejects duplicate JSON keys, floats/nonfinite values, invalid types,
extra fields, noncanonical JSON, invalid names, duplicate/casefold aliases,
missing directory parents, oversized counts/files/totals, and revision mismatch.
A producer-permitted null revision is rejected specifically as unbound by this
exact-revision route.

All remaining physical headers are reconstructed with `TarInfo.tobuf(PAX_FORMAT)`
using independently specified producer metadata. Bytewise comparison supports
the producer's Unicode/long-path local path-only PAX sequences and ASCII fallback
names, including the raw directory slash, without accepting arbitrary PAX/GNU
extensions or alternate tar types. It also fixes the exact merged member order.
Files stream through SHA-256; the manifest, per-file padding, two terminators,
record padding, complete expected size, archive SHA-256 and bytewise EOF are
checked. Hidden files, empty files/directories, retained `manifest.json`, maximum
relative paths and entirely empty input trees remain supported.

The optional encryption summary checks strict success shape, exact revision and
counts only. Its ciphertext SHA-256 is intentionally unrelated to the caller's
plaintext archive SHA-256. No parsing of inner archives or success-shaped native
receipts occurs. No extraction, retained-code execution, subprocess or network
operation is performed.

## Public API coordinated with A09 and A11

- `RetentionError(ValueError)` exposes a fixed whitelisted `.code`; `str(error)`
  is the same code, never retained data or paths.
- `RetentionArchive(archive, expected_sha256, *, expected_revision, summary=None)`
  is the agreed context manager. Normal exit rechecks source paths, descriptor
  stamps, complete archive digest/EOF and optional summary digest before closing.
- `.manifest` and `.entries` return defensive snapshots. Entry names are
  manifest-relative, with root `""`; directory records have `directory` and
  `size_bytes`, and file records additionally have `sha256` and payload `offset`.
- Additional agreed `.manifest_bytes` returns the exact validated JSON bytes for
  byte-preserving restoration. `manifest.json` is not added to `.entries`.
- `.copy_file(name, output_fd)` writes only to a caller-owned new regular
  descriptor, streams bounded chunks, retries short writes, rehashes copied
  source bytes and observes source stability again. It resolves no output path.
- `.assert_unchanged()` performs the complete post-use source checks.
- `.report()` and `inspect_archive(...)` expose retention consistency only:
  `archive_bytes`, `archive_sha256`, revision, counts, `summary_checked`, plus
  explicit `native_execution=not_run`, no retained-code execution, no origin
  authentication, and false native/performance/phase acceptance.

Existing producer public bounds are imported unchanged. The conservative archive
cap is 1,336,299,520 bytes; summary JSON is capped at 64 KiB. The whole archive is
never allocated in memory. The bounded manifest and bounded entry index are
retained; all file payload reads/copies are at most 64 KiB.

## Limitations

The selected digest, expected revision and optional public summary establish
consistency with caller-selected inputs, not authenticated producer origin.
Repeated observations detect changes but cannot exclude every malicious
concurrent writer. Stop writers before inspection/restoration. A valid partial
or failed retained attempt remains valid retention only. The reader supports
the established producer's deterministic format, not general tar archives.
