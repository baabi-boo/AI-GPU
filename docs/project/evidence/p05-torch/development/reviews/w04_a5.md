## Exact reviewed interface

Import the trusted current repository reader, never its retained artifact copy:

```python
with ArchiveReader(absolute_zip_path, external_original_sha256) as archive:
    torch_packet = archive.view("torch")
    report = torch_packet.json("report.json")
    request = torch_packet.document(report["installed_request"],
                                    "snapshots/installed-request.json")
    observations = torch_packet.document(report["observations"],
        "artifacts/installed-observations.json", integers_only=True)
    read_receipt = archive.receipt()
# Publish a successful read receipt only after context exit rehashes the ZIP.
```

`ArchiveReader` hashes the original regular file before ZIP parsing, checks file
identity during reads and rehashes it on successful context exit. Its ZIP
metadata bounds are checked before decompression, and its central-directory
bounds precede allocating the member list. It rejects canonical-name aliases,
file/directory collisions, symlinks/special files, encryption and unsupported
formats. Standard member CRC verification remains active.

`PacketView` supplies `files()`, `read(name, limit=...)`, `identity(name)`,
`verified(descriptor, expected_path=None)`, `json(name, integers_only=False)`,
`document(descriptor, expected_path=None, integers_only=False)`, `inventory()` and
`subview(prefix)`. Descriptors have exactly `path`, `sha256`, `size_bytes`;
boolean sizes are rejected. Files are read directly from the original ZIP, with
streaming hash-only reads available for binary provenance.

`strict_json(raw, integers_only=False)` rejects duplicate fields, nonfinite or
oversized numbers, invalid UTF-8 and excessive depth/node counts. Integer-only
mode rejects float syntax in observation records. It does not coerce boolean
values into integers; semantic schemas must still enforce their own types.
`recorded_absolute(value)` validates canonical POSIX syntax and returns a
`PurePosixPath` without reading that path. `ArchiveError(ValueError)` identifies
contract failures; filesystem I/O errors remain blockers, never passing input.

Default ceilings: 256 MiB original archive, 32 MiB central directory, 20,000
members, 256 MiB per member, 1 GiB declared expanded bytes, 2 GiB charged read
bytes, 100,000 read attempts and 16 MiB JSON. JSON depth is at most 64 and
structure count at most 300,000. The API has no facility to raise these ceilings
from an artifact request.

## Concrete division for the next independent reviews

| Reviewer | Inputs and obligations |
|---|---|
| Numerical | Read `torch/report.json`, its request/observations descriptors and original matrix log. Reconcile actual framework tensor shape/stride/dtype/bits against the nested native owners, frozen fixtures and fresh native comparison. Reuse trusted unchanged pure numerical routines, with pinned source identities, rather than execute retained helpers. |
| Dispatch | Validate the full original raw log before selecting markers; preserve the exact 33-marker chronology. Check native arguments, launches, profiles, intermediate data lineage, explicit host work, owner close and resource restoration. Count each original execution once. |
| Package/provenance | Bind original archive intake metadata to source revision/tree, retained helper/source bytes, manifests, sdist/wheel and package pins, clean environment, command argv/cwd/order/budgets, locked wheel identities, before/after installed inventories and actual framework probes. Reuse reviewed bounded nested wheel/sdist parsers for their retained bytes. |
| Integration/acceptance | Require both formats and all independent decisions; reconcile the three-stage execution totals and failures. Preserve all originals and explicitly distinguish data replay from original installed execution. |

Expected top-level packet views are `native-model`, `python` and `torch`.
`torch/python` is the new stage's retained copy of the original Python packet;
`python/native` and `torch/python/native` are copies of the native packet. The
provenance reviewer must prove their exact tree equality. Those copies add
**zero executions**. Planned distinct totals remain 36 native reference +36
plain-Python +36 framework launches per format, until confirmed from actual data.

Do not call the live `p05_torch_records.verify_observations` on relocated
archives by mocking its filesystem checks or creating fake runner directories.
Its `_framework` and the underlying `_installation` intentionally inspect actual
canonical installed files. Data-only replay may reuse pure helpers such as
strict raw-marker and tensor-byte validation, but must independently prove
recorded path relationships and serialized identities from archive/Git evidence.
A recorded path is metadata; an inventory row is evidence from the original
run, not a claim that its former host file is currently present.
