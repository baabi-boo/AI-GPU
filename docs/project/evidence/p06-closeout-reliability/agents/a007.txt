# A007 hosted closeout interruption correction

Base revision: 43c93ce892f1f3f6c0555597da342709ec9f7e49.
Scope: ci/project/p06_qualified_warm_hosted.py and new ci/project/test_p06_hosted_closeout_interruptions.py.

The hosted finally block previously called writers_finished and observed_native_execution outside closeout error guards. A SIGTERM converted by decorated main into KeyboardInterrupt could escape these reads and prevent final and partial retention receipts.

The correction adds a bounded read-only observation guard. The first KeyboardInterrupt permits one re-observation; ordinary errors receive no retry, and a second failure ends observation conservatively. Errors record fixed failure entries and revoke native_success and orchestration_passed. Previously reconciled native execution remains observable. Confirmed finished writers permit partial packaging and encryption; unresolved writer accounting blocks both. Producer stages are never retried. Schema, resource gates, expected counts and qualification claims are unchanged. stage() was not modified in A007.

- After correction: all 8 new tests passed, 4.542 seconds.

The tests compose HostedCompositionTests without inheriting its tests. They cover real SIGTERM during writer and failed-native-disposition reads, unchanged calls and report bytes during pure re-observation, repeated interrupts, ordinary errors, unknown launches, incomplete cleanup, and missing or malformed nested receipts.
