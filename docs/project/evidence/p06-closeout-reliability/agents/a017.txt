Confirmed root cause
The CLI inherited SIG_DFL for SIGTERM. Its age subprocess runs in a different
process group (start_new_session=True). Sending SIGTERM only to the encrypt CLI
therefore killed Python without reaching its BaseException cleanup/retention
path, and the age leader plus its descendant remained running. Direct
KeyboardInterrupt tests did not exercise this process-level default behavior.

Bounded reproduction
All input is synthetic. The test double emits exactly 51 bytes of partial,
synthetic age-shaped ciphertext plus synthetic private stderr, starts one inert
child, and has a 15-second self-bound. The test waits for observed retained
bytes, then sends real SIGTERM only to the CLI. Readiness and CLI completion
are each bounded at five seconds. Cleanup in the test's finally terminates the
fixture group even when the pre-fix regression assertions fail. No real private
evidence, network calls, age cryptography or native GPU work was used.
