Assignment a011: hosted prelaunch status emission

Status: proposed change and static source audit only. This report is not executed test or native evidence.

Static finding: stage() appends an unresolved stage row and emits its running status before entering the run_bounded try block. An emission OSError or KeyboardInterrupt therefore prevents launch but leaves process_started=None and cleanup_complete=False, blocking safe partial retention and making a native-supervisor nonstart unknown.

Proposed production change, for root to apply: wrap only the running-status emission in an (Exception, KeyboardInterrupt) catch; mark process_started=False, cleanup_complete=True, outcome="blocked", exit_code=None, and reason=type(error).__name__, then rethrow into existing closeout. Do not retry emission or call the supervisor. Keep the run_bounded exception handler and a007 closeout changes unchanged.
