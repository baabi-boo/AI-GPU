# Wave 4 agent 2 — paired circuit measurement runner

## Scope and implementation

Authored only `ci/project/p06_mpm_synthesis.py` and this receipt. The runner
creates a separate checkout of production reference
`4df7186edbca82b21b2b8cba9b3b192248b99209`, copies the identical candidate
synthesis wrapper, two catalog files and logic-build specification, and verifies
the reference MPM decoder against the pinned Git object. It requires clean
candidate source and a pre-fetched reference object; it changes neither checkout's
production RTL.

Eight Beacon measurements cover parent/candidate × RV32/RV64 × PERF off/on,
followed by eight independently elaborated generic Yosys measurements. Every
variant uses a freshly configured tree. Original `logic_gate` return codes,
verdicts, reasons and reports remain retained; the official parent/head Beacon
diff runs separately, preserving depth/area regression exits and metric deltas.
The report names `NO-BASELINE` and regressions without creating a golden,
changing a threshold or accepting a phase.

As explicitly approved by root, exit zero means **complete paired measurements**,
not a passing synthesis gate. Missing metrics, malformed reports, tool failures,
resource stops and source/tool/generated-input identity changes are fatal.
`gate_outcome` remains `fail` or `not_passed`; independent review must assess
observed costs before landing.

The runner retains commands, bounded logs, source/tool hashes, generated
configuration, Beacon reports, Yosys source-file identities, generic scripts,
netlists, cell counts and longest topological paths. Limits are two jobs,
one thread, 4 GiB sampled process-group RSS, 15 GiB disk reserve, 16 MiB logs,
and bounded configure/build/diff durations.

## Validation and limits

AST parsing and `--help` succeeded. Six temporary host-fixture tests passed
in 0.003 seconds: source-list/script generation, injection rejection, generic
metrics parsing, inconsistent totals, missing path results and retained blocked
preflight. The current candidate source identity inventory also completed.
These are host checks; **no Beacon synthesis or Yosys circuit execution ran**
locally because the required disk reserve was unavailable.

Hosted prerequisites were communicated to the workflow owner: installed CIRCT,
Foldsim, Yosys/ABC, PyYAML and pyslang 11/12. Generic Yosys confirmation uses the
canonical ASIC source-generation path, then generic mapping; it supplies cell
and path comparisons, not Liberty area, STA, Fmax, physical timing or calibration.
Root review corrected an overstrict assumption: shallow leaves may have an empty
watch-level unit map. The parser now checks that map’s type, positive endpoint
count and required nonempty raw reports. Independent runner tests and hosted
execution remain necessary.
