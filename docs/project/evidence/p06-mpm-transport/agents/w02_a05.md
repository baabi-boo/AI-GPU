## Implemented

The wrapper instantiates production `VX_dcr_data` and `VX_csr_mpm`, connecting
their real interfaces. Raw 32-bit host tags enter the DCR request and returned
words leave the DCR response. Counter injection uses flat 44-bit inputs wired
directly into production counter/performance fields. No copied decoder, macro
mock, replacement DUT or added pipeline stage is present.

Cycle/instret have nine independent literal value/low/high triples, including
zero, one, `ffffffff`, rollover, asymmetric words, bit 43 and the 44-bit maximum.
The PERF branch supplies 23 distinct CORE/ICACHE/DCACHE/L2/L3/MEM/LMEM/coalescer
inputs, plus three TCU inputs when enabled. Tests check both half orders,
reconstruction, repeated reads, adjacent indices, class selection, reserved
classes/holes and high-word bits 31:12 equal zero. Every class's index-three
representative also traverses all nine boundary vectors. PERF-off checks retain
base counters and require selected user slots to return zero.

Every successful read requires capture on the first rising edge, response on
the second, and deassertion on the third. Inactive request-wire poisoning checks
latched class/index isolation. Negative cases check wrong cores (including
nonzero upper target bits), writes, unrelated addresses and invalid requests.
Core IDs zero/one and reset cancellation of a captured request are exercised.

The Makefile includes the generated tree's `config.mk` and ordinary
`hw/unittest/common.mk`. It does not force XLEN/PERF/TCU. Success output reports
XLEN, PERF, TCU, read/assertion counts and response-edge count; data failures
report tag, tick, actual and expected words.
