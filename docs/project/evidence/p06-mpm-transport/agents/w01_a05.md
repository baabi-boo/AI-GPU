## Routing matrix

Test CORE's last mapped index30 and holes 1/24/25/31, both halves. BASE=0 user slots return zero. With PERF disabled, RTL user slots remain zero; cycles/instret still work.

Use distinct cores 0/1 across socket/cluster boundaries; verify selected-core isolation and runtime `core_id=0xffffffff` summation. Check SimX class restoration after interleaved reads. Public invalid addresses `0xAFF/0xB20/0xB80` must reject.

Characterize separately: reserved class2/255 and disabled extension classes return RTL zero but abort SimX user reads; missing core leaves SimX output unchanged/success and causes no RTL response. Bound negative tests; do not silently redefine these contracts.

## Device CSR invariants

For cycle/instret, RV32 retains low/high aliases; RV64 low address retains the full value and high alias remains zero. RTL device user MPM reads remain zero. Preserve SimX's existing device user-class decoding; host adaptation must not rewrite it.
