## Implemented scope

The host test extracts `Core::Impl::dcr_read` and public
`vx_device_mpm_query` verbatim from their production files. It compiles them
against a narrow deterministic CSR backing and scripted CP, respectively.
Production `CSR_READ_64` is also extracted and compiled; address constants come
from `VX_types.toml`, and the real public runtime header supplies API types.

Ten literal value/low/high triples cover zero, one, the low-word maximum,
bit 32, bit 32 plus one, mixed bits, the 44-bit maximum, bit 44, a mixed
full-64-bit value, and all 64 bits set. Both XLENs check high-first/low-first
and repeated reads, adjacent indices, 13 valid class selectors, class restoration,
interleaved class banks, and exact requested CSR addresses. Public API checks
use literal packed tags, reconstruct all ten values, sum two distinct cores
with carry, reject invalid inputs, and inject every low/high or capability
failure while checking output preservation and early termination.

Compiled CSR-macro checks retain full RV64 low reads, absent RV64 high aliases,
and RV32 split reads. Focused RTL source assertions guard its architectural
counter-width/alias branches; they are source checks, not RTL execution or a
whole-file hash gate.
