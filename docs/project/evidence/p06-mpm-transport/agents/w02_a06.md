## Implemented scope

`test-mpm-transport` links the actual SimX `$(OBJS)` and drives
`Processor::dcr_read` through cluster/socket/core and `CsrUnit`. The processor
is reset before deterministic seeding through existing `Core::perf_stats()`;
no simulation ticks advance the counters. There is no substituted counter
getter or extracted production-method copy.

All ten independent literal seed/low/high triples cover cycles and instret,
with unequal neighboring values, low-first/high-first/repeated reads, separate
reply/reconstruction assertions, and full 64-bit SimX values. Cycle/instret
reads alternate the seven unconditional supported classes and any enabled
extension classes. PERF builds additionally cover CORE sched_idle/index 3,
active_warps/index 4, stores/index 30, and holes 1/24/25/31. BASE user zeros are
checked in every build; no PERF-off CORE-zero behavior is invented.

Every host reply checks restoration of the real initial BASE class. Existing
public interfaces provide no persistent nonzero class setter, so that stronger
restoration case is not claimed. Direct device CSR reads before and after host
reads check RV32 halves, RV64 full low values/high-alias zero, and BASE user
zeros. Only the first core is seeded; cross-core/socket/cluster isolation,
unsupported classes, and public-runtime reconstruction are outside this harness.

The Makefile includes the executable/run target, configuration dependency,
generated header dependencies, PHONY entry, and executable cleanup. Output
names XLEN/PERF, check count, and exact seed/actual/expected mismatches.
