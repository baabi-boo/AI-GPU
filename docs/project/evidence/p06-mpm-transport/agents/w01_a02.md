## Finding

**F3, high confidence, static-proof, preexisting:** RV64 host MPM loses bits above 31.

- `VX_types.toml:4–8` fixes DCR width at 32 and low/high bases at `0xB00`/`0xB80`; hardware counters are 44 bits (`VX_gpu_pkg.sv:78`).
- `VX_dcr_data.sv:38–44` correctly maps selector bit 5 to the high address independently of XLEN.
- `VX_csr_mpm.sv:16–23` omits high-address cases on RV64; `:47` truncates low-address results to 32 bits; `:55–64` defaults unmatched high reads to zero.
- Runtime correctly reads both halves and assembles them (`sw/runtime/common/perf.cpp:259–285`). For counter `0xABC_89ABCDEF`, baseline RV64 yields `0x0000000089ABCDEF`; expected high word is `0x00000ABC`. This example is derived, not simulated.
