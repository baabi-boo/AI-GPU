the production qualified-warm supervisor. Empty command lists and lists whose

false-like invalid value cannot prove that no child ran. The correction does
not infer start, cleanup or exit status, and still clears the fresh-build pass
flag while preserving the first failure reason and all false claims.

## Separate F2 — SIGTERM outside the monitor skips dependency closeout

**Confidence: high. Evidence: static-proof plus bounded process reproduction.**
`Builder.execute` handles `KeyboardInterrupt` but installs no SIGTERM handler.
`baseline_process.run_bounded` installs handlers only during command monitoring
and restores the preceding handler afterward. A SIGTERM during source
collection, source retention or the intervals between commands can therefore
terminate the builder without its `finally` closeout.

Executed two isolated Python probes with a 10-second outer subprocess timeout:
one sent SIGTERM at entry to the patched `collect_source` boundary, before any
command; the other first completed a real local Python command and then sent
SIGTERM at the same execution boundary. The only mocked production operations
were source collection and lowering the monitor's free-disk requirement for
that tiny local test child. The production execution/finalization methods and
the production hosted writer guard were used unchanged.

| Boundary | Child process result | Retained dependency report | Hosted writer guard |
|---|---|---|---|
| Before the first command | Builder exited `-15`; no command launched | `state=running`, `outcome=blocked` | `false` |
| After a completed Python command | Builder exited `-15`; command started, cleanup complete, exit `0`, outcome `pass` | `state=running`, `outcome=blocked` | `false` |

In both probes the fresh-build flag and all seven claims remained false.
The writer check used a finished outer supervisor with completed cleanup, so
the unfinished dependency report alone still prevented partial retention.

Minimal executable reproduction of both signal boundaries, from the source
root using the environment below and `PYTHONPATH=ci/project` (the exact
documented snippet was also rerun successfully):

```python
import json, signal, subprocess, sys, tempfile, textwrap
from pathlib import Path
import p06_dependency_build as build

program = textwrap.dedent('''
    import os, signal, sys
    from pathlib import Path
    from types import SimpleNamespace
    from unittest import mock
    sys.path.insert(0, sys.argv[1])
    from baseline_process import run_bounded
    import p06_dependency_build as build
    workspace = Path(sys.argv[2])
    producer = build.Builder(SimpleNamespace(source_dir=build.ROOT,
        workspace_dir=workspace, output_dir=workspace / "evidence",
        expected_revision="1" * 40))
    def interrupt(_):
        if sys.argv[3] == "after-child":
            producer.command("local-child", [sys.executable, "-I", "-B", "-c",
                "print('completed local signal probe')"], workspace, timeout=5)
        os.kill(os.getpid(), signal.SIGTERM)
        raise AssertionError("SIGTERM unexpectedly returned")
    def child(*args, **limits):
        return run_bounded(*args, **dict(limits, min_free_bytes=1))
    with mock.patch.object(build, "collect_source", side_effect=interrupt), \\
            mock.patch.object(build, "run_bounded", side_effect=child):
        producer.execute()
''')
for boundary in ("before-child", "after-child"):
    with tempfile.TemporaryDirectory(prefix="a07-sigterm-") as directory:
        result = subprocess.run([sys.executable, "-I", "-B", "-c", program,
            str(build.ROOT / "ci/project"), directory, boundary],
            capture_output=True, timeout=10)
        report = json.loads((Path(directory) / "evidence/report.json").read_text())
        assert result.returncode == -signal.SIGTERM
        assert report["state"] == "running"
        print(boundary, result.returncode, report["state"], report["commands"])
```
