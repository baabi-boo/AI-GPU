[A02](a02.md). Base: `e3ad6bd1e2b002aa234d57cd8a02519cec915830`; validation used
the uncommitted working tree with the two source identities below. Concurrent
agents' changes were preserved.

ancestry as unknown. This is an additional bounded admission observation, not

## Regression coverage

The new `ci/project/test_p06_hosted_native_capacity.py` contains nine integration
tests using the production gate and production capacity observer over synthetic
kernel files. Existing hosted fixtures replace all operational children with
inert receipt writers; no downloads, provisioning, native workloads or real
encryption run.

Covered cases are: parent usage rising from 1 to 5 GiB under an unchanged 8 GiB
limit while host availability remains 8 GiB; independent host-memory decline;
incomplete final observation; source and attempt disk shortfalls; fresh capacity
exactly at 4 GiB memory/headroom and 15 GiB disk; receipt creation and partial-write
errors; and a failed acquisition receipt that must precede any refresh. The tests
check native non-invocation, explicit `not_run`, writer completion, partial
packaging/encryption composition, private receipts, receipt availability before
native launch, unknown effective capacity and unchanged budgets.

No existing shared tests were modified.
