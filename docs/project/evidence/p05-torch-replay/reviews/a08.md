# Agent 08 — Native retained-data replay implementation

## Owned changes

- `ci/project/p05_replay_native.py` implements
  `verify_native(outer_view, *, expected_revision, expected_format)`.
- `ci/project/test_p05_replay_native.py` contains 16 synthetic host-only tests.

The interface returns the agreed `native_matmuls`, `native_models`,
`model_cases`, `python_report`, `python_request`, `python_observations`,
`python_raw_log`, and `counts`. It additionally returns `native_report`,
`model_binding`, `matmul_binding`, `native_source`, and `python_source` for
installation and outer-driver reconciliation. Source values are full
`{checkout, files}` snapshots. Counts use the existing five-key dictionary.

## Enforcement

Every member in `native-model` equals its `python/native` copy byte for byte;
every `python` member equals its `torch/python` copy. Copies contribute no
additional execution population. The native packet has an exact member closure;
native and Python command IDs/order, log member sets, successful bounded
receipts and log hashes are checked. Exact argv, cwd, environment and timeout
relationships are reconstructed for native build/header/launch commands and
Python packaging/installed commands. Native/Python helper inventories are exact
20/24-member reviewed constants; retained source bytes and identities are joined.

The four independent frozen fixture byte digests are pinned. The current trusted
P02/P04 fixture adapters are called only with the reviewed module's fixed local
repository root. Native raw logs go through trusted P03/P04 parsers, with total
input bounds around P03. Actual hidden/bridge/output model results, operands,
poisons, cleanup, resources and ABI dispatch remain validated by those parsers.
Returned comparator dictionaries are freshly parsed, never report aliases.

Compiler stamps are parsed as data with the trusted pure P03/P02 parsers.
Bindings are reconstructed from source, compiler, artifact and dependency joins,
then canonical SHA-256 IDs are compared with all request/report/log IDs. Native
run/launch/word/transfer summaries are independently derived and reconciled.

No retained code is imported or executed; no producer path is opened; no native
runner/live observation validator, build, download or broad suite is invoked.
The trusted `p05_execute.py` file is read with `ast.parse` solely to obtain the
current reviewed `PACKAGE_PROBE` literal, without importing the producer.
