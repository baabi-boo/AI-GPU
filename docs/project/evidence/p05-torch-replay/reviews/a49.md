identity matches do not rehash the historical producer filesystem. The 193
submodule source paths (2,316 repeated receipt rows) lack comparable superproject
blobs and were not byte-verified. Five top-level gitlink revisions match; three
nested gitlink observations remain unverified. Eleven third-party wheels,

observed tool identities remain absent-byte evidence. Generated outer files
(82), nested package metadata (22), nested build pins (six), and compiled outputs
are separately classified, not claimed as exact Git source matches. No native,
