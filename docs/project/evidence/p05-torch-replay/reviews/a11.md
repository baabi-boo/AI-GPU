## Retained boundary and identity joins

- `RetainedIdentity` is a frozen dataclass whose accepted contents are exact strings, tuples of exact three-element tuples, and exact bounded integers. Digest spelling, canonical POSIX paths, duplicate paths, and boolean-as-size confusion are rejected. Its data contains no callbacks or filesystem handles; the verifier rejects subclasses of the identity itself.
- The retained base verifier independently validates the frozen request and hashes canonical request bytes before reconciling observations. Matching changes to request and observation pins cannot bypass the supplied immutable request digest.
- Recorded paths are handled lexically. The retained installation requires the exact CPython 3.12 `vortex_ai/__init__.py` location, sibling native extension layout, copied interpreter location, bundle library paths, immutable build pins, and receipts for all three required installed files.
- The framework adapter is inert exact `bytes`; its path, digest, length, request identity, observation identity, and installed receipt are joined. Mutually changing request/observation adapter digests still fails against the original installed receipt.
- The helper intentionally does not authenticate arbitrary caller-supplied facts. Its docstrings state the trusted archive driver's responsibility. I checked the integration boundary at `p05_replay_installation.py`: the complete framework request is compared against the frozen contract pin and the retained wheel adapter before identities are constructed. This spot check does not replace the separately assigned complete driver review.
