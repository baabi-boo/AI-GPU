## Implemented

- Added explicit `p06_preflight_enable_lifetime()` selection before the first
  processor construction. Repeated or late selection fails and records a
  violation; no environment or default-mode fallback selects the feature.
- Extended internal model observations with the actual read-only
  `Processor::pending_mem_reads()` value in lifetime mode. Construction,
  snapshots, real run boundaries and actual destructor entry use that route.
- Added a bounded 33-element `RunObservation` trace and
  `p06_preflight_get_run()`. Each attempted run records its ordinal, model
  states, DCR/flush counts, real-call entry, successful void return and
  exception outcome.
- Before the real reset-bearing call, reject a non-live, non-idle, running or
  nonzero-pending state. After a successful call, require a drained state and
  exactly one reset increment. Reject exhausted reset generation before entry.
- A 34th run is rejected before real entry, marks trace overflow and invalidates
  the lifetime. DCR traces retain their existing bounds and now report overflow
  in the lifetime observation too.
- Added pending values on both sides of every MPM and cache-flush read. In
  lifetime mode both boundaries must be idle, non-running and pending zero.
- Failed run/read observation is best-effort and `noexcept`, preserving the
  original typed, standard or nonstandard exception even when a later model
  observation also fails. Legacy x3/`gp` values are never interpreted as a
  returned status from the void checked entry.
- The destructor captures the live state before the real destructor, always
  performs disposal, and observes only platform state afterward. An invalid
  pre-destruction state remains a violation even when disposal completes.

The default v1 JSON printer remains unchanged in its separately owned source;
its explicit field lists omit these internal additions. New pending queries
and lifetime guards are opt-in. The existing exceptional read cleanup now also
preserves its original error instead of allowing a secondary observation
failure to replace it.
