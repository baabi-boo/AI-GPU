## Probe

The separate C++ executable uses real Processor/RAM and the existing three-word
scalar program. Fresh contexts observe legacy gp values 7 and -1. Each launch
steps actual `Processor::cycle()` calls until both the core and platform drain;
the cycle return alone is insufficient because it does not include platform
inflight work. Repeated pending getter calls are bracketed by clock, reset,
core cycle/instruction, running, idle and gp observations. The probe requires
at least one nonzero pending observation followed by zero at drain. It then
executes a checked void launch and verifies preserved legacy gp/completion.

A separately compiled `P06_PENDING_FORCE_ZERO` control replaces the probe's
getter result only; it does not mutate/rebuild model storage or the measurement
application. Its required result is exit 1 with exactly
`FAILED pending_reads native_probe: pending getter did not observe an outstanding read`.
Both processes emit the actual selected libsimx/Ramulator loader paths.

## Runner and provenance

The runner requires an explicit completed live managed report, source directory,
existing build directory, fresh output directory and exact expected revision.
It is executing live build validation, not an inert archive reader. It selects
the host compiler independently through clean PATH/optional host-bin, compares
its identity with the original build, revalidates full compiler stamps through
the existing strict shared validator, and removes only dependency-output flags
before compiling each separate probe. No recorded command is executed.

It compares current source, generated/model products and selected dependency
identities with the managed build; retains command logs, source/helper bodies,
probe executables, loader observations and before/after identities; and preserves
the expected negative command as an actual failed command. Native limits remain
15 GiB disk reserve, 4 GiB memory/RSS, one process, 120-second compile and
180-second run bounds. Fresh dependency compilation provenance, complete
qualification and all seven acceptance/readiness claims remain unresolved/false.
