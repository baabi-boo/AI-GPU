## Invariants and fixes

- The pass summary is staged privately. Both public no-clobber links have known
  inode ownership before their syscall; neither link completion nor a completed
  `_write_json` followed by KeyboardInterrupt can escape ownership accounting.
- Before commit, recovery withdraws its owned pass summary first. It removes
  public ciphertext only after summary withdrawal succeeds and the same private
  ciphertext inode remains. Failed summary withdrawal preserves the ciphertext;
  missing/replaced private copies preserve the last public encrypted copy.
- Commit follows both links, public-directory fsync and an observation that both
  public paths still identify the owned inodes. After commit, interrupted private
  unlink cannot revoke either public file, including when unlink already removed
  the private ciphertext. Private cleanup also checks inode ownership.
- Foreign/replaced paths remain untouched. The success schema and public names
  are unchanged. A private staged-summary name and `publication_committed` in
  private exception diagnostics distinguish cleanup interruption from rollback.
  No crypto or age streaming changes were needed.

Seven new regressions cover A29's three exact interruption gaps, interruption
after summary linking, failed summary withdrawal, missing/replaced private
ciphertext, and observed public replacement before commit. Existing collision,
foreign-inode, byte-preservation and plaintext-exclusion checks remain present.

## Limits and next step

Ordered recovery is not an atomic multi-file crash transaction. Abrupt
termination, storage errors, repeated interruption, same-user replacement
between stat/unlink and in-place mutation can prevent recovery or durability.
A valid committed public pair can survive a caller-visible interruption; callers
must still enforce their invocation/validation rules before upload. No external
contract change is essential. No native execution, real-age rerun, downloads,
full governance, performance or acceptance claim. Next: independent final-tree
review and root's strict governance qualification.
