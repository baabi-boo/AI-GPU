## Actual matrix

“Eligible” below means encryption and hosted validation succeed, followed by a
successful upload. Local ciphertext alone is not durable hosted retention.

| Condition | Private evidence / encrypted delivery | Job and acceptance scope |
|---|---|---|
| Missing workflow configuration | Checkout/attempt skipped; no encrypted packet. | Failure; native not run. |
| Preflight or Python setup failure | Best-effort local partial closeout after checkout; age provisioning was never reached, so no encrypted delivery. | Failure; native not run. |
| Known prelaunch block | Boolean `process_started=false`, `cleanup_complete=true` permits partial closeout; delivery eligible only if encryption tooling/configuration is available. | Failure; no completed experiment. |
| Unknown launch or unresolved cleanup | Packaging/encryption blocked; originals and available receipts remain local. | Failure; unobserved native-supervisor launch is `unknown`. |
| Finished native failure | Partial packet eligible when all required writer/cleanup observations finish. | Failure despite successful retention. |
| Packaging failure | Only already-created `retention/` bytes are eligible; completeness unestablished. Surviving duplicate hardlinks block encryption. | Failure; packaging remains failed. |
| Encryption failure | No upload authorization, even when interruption leaves a committed public-named pair locally. | Failure; no durable closeout established. |
| Cancellation/abrupt termination | New hosted work does not start after cancellation; active closeout/upload is unguaranteed. Previously validated output may upload if reached. | Record actual provider conclusion; infer no acceptance. |
| Complete valid experiment, failed hypothesis | Complete original/envelope eligible. | Hosted job can pass; replay may report `not_satisfied`; no performance/phase/hardware acceptance. |

The encrypted selection is `attempt/retention/`: packet products/receipts,
packaging log and pre-encryption hosted closeout. Fetched inputs/repositories,
installed tools, unselected workspace files, final attempt receipt, encryption
invocation log, `public.PRIVATE/`, and preflight/entry stderr remain private
ephemeral files. Public upload selects only ciphertext and sanitized summary.
