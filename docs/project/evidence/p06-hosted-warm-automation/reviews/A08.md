## Interface and interpretation

`observe_capacity(reader=None, *, clock=time.monotonic)` returns an advisory dictionary. The injected reader receives `(path, max_bytes, mount)` and returns `ReadResult(body, identity)`; pure parsers are independently testable. The no-option CLI writes bounded JSON to stdout and returns nonzero for unknown/blocked capacity. There are no waiver, allow-unknown, ancestry-assertion or threshold override flags.

The report exposes `known_memory_shortfall`, `observation_complete`, `host_available_bytes`, `visible_limit_bytes`, `visible_headroom_bytes`, `topology_stable`, `limits_stable`, and redacted process-membership/mount mapping metadata. Level zero identifies the visible process cgroup. Raw machine paths and ancestor names are omitted.

Host `MemAvailable` is sampled twice. Every mapped visible ancestor gets two `cgroup.type`, `memory.max` and `memory.current` samples, plus a separate `memory.high` observation. Finite headroom uses that ancestor’s own usage, conservatively combines valid samples, clamps usage above the limit to zero, and takes the minimum across observed ancestors. Equality at the unchanged 4,294,967,296-byte threshold is not a shortfall. Swap never increases RAM capacity. Missing/malformed files stay unknown; stable low readings survive unrelated missing ancestors. Changed membership, mounts, identities or limits prevent a complete visible observation.

`observation_complete` means only that the supported visible observations completed successfully. `full_ancestry_status` and `effective_capacity_status` always remain `unknown`; `ancestry_complete` and `effective_headroom_bytes` remain null. No full-root witness is implemented. Namespace-relative `/` and all visible `max` values cannot establish unlimited capacity. Every native authorization, qualification and acceptance boolean is false; `native_execution` is `not_run`.

## Bounds and safety

Limits: 64 KiB meminfo/membership, 1 MiB mountinfo, 4 KiB scalars, 2 MiB aggregate bytes including overflow detection, 512 file reads, 1,024 OS read calls, 64 path components/ancestors, 4,096 mount records, 4,096-byte paths, 64 KiB CLI JSON, and a two-second monotonic budget. The deadline is polled and cannot interrupt a blocked kernel/injected read.

Read-only descriptor traversal rejects symlink components, nonregular files, oversized files and cgroup device crossings. Mount mapping uses path components, decodes mountinfo escapes, rejects overlays and ambiguous/v1/hybrid layouts, and avoids directory scans. Unsupported escaped membership/control-character paths fail closed rather than guessing filesystem names. Endpoint stability cannot exclude intervening changes; observations reserve no capacity.
