## Findings and fixes

- **F3, high confidence, static proof:** requiring every visible ancestor to
  expose `cgroup.type`, `memory.max`, `memory.current` and `memory.high` made
  ordinary cgroup-v2 host roots incomplete, so the hosted completeness gate
  always rejected them. Linux documents all four as non-root interfaces.
  The observer now recognizes their absence only at a mapped `/` root after
  explicit `ENOENT` for every file in both samples and a readable, unchanged
  `cgroup.controllers` identity/content containing `memory`. Its public status
  is `supported_nonroot_interfaces_absent`; this describes visible interfaces,
  never unlimited memory or complete ancestry. Missing/disabled/malformed
  controllers, permission errors, partial absence, namespace-subtree mappings,
  changed identities/content and disappearing/appearing files remain incomplete.
- **F2, high confidence, static proof:** real read bytes were counted only after
  a successful return. A late `OSError` could discard partial-read accounting
  and permit later reads past the aggregate budget. Each successful `os.read`
  chunk now consumes the budget immediately. Injected-reader accounting remains
  bounded separately. A regression observes four consumed bytes before a read
  failure, then exhausts an eight-byte total on the next bounded read.

## Review conclusions

Parsing remains strict and bounded; v1/hybrid, ambiguous mapping, unsafe paths,
overlays and symlinks fail closed. Overlay detection now includes the new
controller probe. Finite parent headroom uses each parent's own descendant
usage and conservative samples; a low stable leaf survives unrelated unknown
ancestors. Equality at 4 GiB is preserved. Throttle and swap observations never
increase hard RAM capacity. Controller, membership, mount and sampled-file
identity changes prevent completeness. No waiver flag or native authorization
was introduced. Root absence leaves `limits_stable` null; effective capacity,
effective headroom and full ancestry stay unknown/null.
