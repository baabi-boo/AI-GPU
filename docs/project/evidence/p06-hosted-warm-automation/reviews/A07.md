## Interface and outputs

Python API:

```python
package_success(source_dir=source, workspace_dir=workspace,
                output_dir=new_output_directory, writers_finished=True,
                extra_roots={"acquisition": acquisition_evidence})
package_partial(source_dir=source, workspace_dir=workspace,
                output_dir=another_new_output_directory, writers_finished=True,
                extra_roots={"acquisition": acquisition_evidence})
```

The functions return the standalone inventory receipt. All paths must be canonical absolute literals. Extra roots explicitly select acquisition/supervision files or directories; overlapping selections reject. Outputs must be outside source, workspace, and all selected input roots. A fresh output directory is required; existing paths are never overwritten.

CLI:

```sh
python3 -B ci/project/p06_qualified_warm_pack.py success \
  --source-dir /absolute/source --workspace-dir /absolute/workspace \
  --output-dir /absolute/new-private-output --writers-finished \
  --extra-root acquisition=/absolute/acquisition-evidence
```

Use `partial` instead of `success` to retain an interrupted/failed attempt. Repeat `--extra-root LABEL=PATH` for additional explicit roots.

Success creates:

- `qualified-warm-original.PRIVATE.zip`: exactly the regular-file populations under `dependency-build/` and `qualified-warm/`, including hidden locks and opaque outputs. No added manifest, wrapper receipt, or external log enters this ZIP.
- `qualified-warm-envelope.PRIVATE.zip`: every other existing `workspace/evidence` file, including full orchestration receipts, raw logs and retained helpers, plus explicit extra roots. The native original is not nested here; the later transport layer must retain both ZIPs and the receipt together.
- `qualified-warm-pack.PRIVATE.json`: raw ZIP SHA-256/size, full member SHA-256/size inventory and source file identities, verification observations, PRIVATE classification, false acceptance claims and limitations.

Partial retention creates `partial-attempt.PRIVATE.zip` plus the inventory receipt. Every member has a `partial-attempt/` prefix. Missing native roots remain missing. Existing malformed, unfinished and failed-cleanup records remain unmodified and are recorded as unresolved. Acquisition-only retention works before workspace creation.

All output directories use mode 0700; files use 0600, independently of permissive umask. The CLI prints only a bounded status summary; raw contents, machine paths and exception text are not printed. Raw originals may contain Micron confidential/proprietary source notices. No upload, public export or cryptography is implemented.

## Enforcement and verification

Success requires the new runner's finished matching orchestration receipt, finished stage reports, stage cleanup completion, exact raw report/log/helper bindings and recorded source/input stability. Both modes require the explicit writer-finished assertion. Descriptor reads reject symlink ancestors, links, multiply linked files and special files. The pinned replay reader supplies path validation and ZIP bounds: 256 MiB compressed, 1 GiB expanded, 20,000 members and 32 MiB central directory; dependency file bounds remain 64 MiB.

The packager inventories and hashes all selected regular files, verifies identities during copying, rereads every ZIP member through the pinned reader, repeats the full source inventory, and rehashes the final published ZIP pathname. Exclusive publication rejects collisions. Exceptions/interruption retain `incomplete-*` bytes and a best-effort `packaging-failure.PRIVATE.json` with available partial-file hashes, without a successful finalized receipt.
