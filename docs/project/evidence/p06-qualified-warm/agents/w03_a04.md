## Investigated report-identity concern

The proposed concern about a late 16 MiB identity limit was disproved against
the actual frozen archive helper. `PacketView.identity()` defaults to
`MEMBER_BYTES`, which is 256 MiB; the 16 MiB default belongs to `read()` and the
historical JSON parser. The new report read and decode explicitly enforce
64 MiB before the final identity operation. Other JSON members retain their
old bound.

An independent bounded probe created a real temporary ZIP with a 17 MiB
`report.json` consisting of `{}` plus JSON whitespace. The selected report view
decoded it and its final identity reported the full byte count. An equally
large `other.json` in that same ZIP was rejected. The temporary archive was
removed automatically. This probe tests size-routing mechanics only, not a
semantically complete report.
