## Concrete ledger contract for the coordinator

Create `execution-ledger.json` in this evidence directory **only after all 60
workers complete**. The following is a schema description; it deliberately
contains no invented future worker records.

| Field | Required value or type |
| --- | --- |
| `schema_version` | Integer `1` |
| `source_implementation` | Full implementation SHA above |
| `source_tree` | Full tree SHA above |
| `counts` | Exactly `{"agents":60,"waves":10,"agents_per_wave":6,"completed":60,"coordinator":0,"supplemental":0}` |
| `agents` | Exactly 60 objects, one for every `w01_a01` through `w10_a06`, six per wave |
| Entry `name`, `wave` | Canonical name and matching integer wave |
| Entry `agent_id` | Actual nonempty tool-returned worker ID; unique; not `root` or `/root` |
| Entry `task`, `scope` | Nonempty truthful descriptions of completed work |
| Entry `report` | Exact repo-relative `docs/project/evidence/p06-qualified-warm/agents/<name>.md` |
| Entry `sha256` | Lowercase SHA-256 of the actual final nonempty report bytes |
| Entry `state` | Exactly `completed` |
| `coordinator_attestation` | Object described below |

The attestation must have `coordinator: "/root"`,
`basis: "actual_tool_history"`, `actual_invocations: 60`,
`completed_invocations: 60`, `excludes_coordinator: true`,
`excludes_supplemental_probes: true`, and a nonempty truthful `statement`
attesting that each unique ID came from an actual worker invocation and each
worker completed. Follow-ups and supplemental probes must not create extra
worker counts. The coordinator must derive these facts from actual tool
history. This program checks that the attestation exists and has the required
structure; it cannot independently authenticate conversation tool history.

The program also rejects duplicate JSON keys, duplicate names/IDs/reports,
missing workers, noncanonical paths, traversal, symlinks, nonregular/empty
reports, report hash mismatches and incomplete states. A report edited after
ledger assembly requires updating its hash and rerunning validation.
