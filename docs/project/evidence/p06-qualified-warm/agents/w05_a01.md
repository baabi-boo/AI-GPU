event. Descriptor-relative opens are recorded only as unresolved labels because

complete filesystem syscall tracing. Module and declared-input closure checks
are separate from that supplemental observation.

This review reran **zero** governance unittest IDs and zero native processes.
The parent's 89-test run and original historical replay are separate evidence.
