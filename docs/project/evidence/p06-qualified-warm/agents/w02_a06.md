## Integration coverage

The positive public API test preserves actual source, build, dependency-link,
loaded-library, raw record, numerical, lifetime, chronology, stability, member
inventory, and analysis reconstruction. It forbids native process execution,
shell execution, retained Python execution, archive extraction, writes and
nonallowlisted producer filesystem access. Both the direct public reader and
the actual ZIP envelope pass. The ZIP uses only the exact `dependency-build/`
and `qualified-warm/` roots below an explicit prefix; a repaired ZIP containing
an unrelated sibling member is rejected.

The 11 test methods cover complete success and these rejection cases:

- Missing, reordered or duplicated process population with a recomputed report.
- Missing or reordered raw operations with repaired command, log inventory and
  report hashes.
- A raw transcript copied between two measured pairs with repaired outer
  hashes; the selected process identity still rejects it.
- The historical native caller substituted for the new source extension with
  repaired source descriptors, source snapshots and the caller-selected pin.
- An interior run with pending reads despite valid aggregate population counts
  and repaired log identities.
- A process binding rehashed around an alternate host binary and common-build
  identity; the reconstructed shared format build rejects it.
- A final prerequisite input stability digest that changes after all 24
  transcripts have been reconstructed.
- An unbound native member included in a repaired retained inventory.
- An incomplete native packet blocked before analysis; a wrapping observer
  preserves the actual analysis implementation and confirms it is not called.

Analysis retains all 24 batches, excludes 24 prime operations from timing and
four warmup processes from conditional criteria, and includes all 20 measured
processes. Historical false claims and phase/performance acceptance remain
false.

## Synthetic boundaries

This is invented test data, not a captured native warm original. The fixture
inherits a synthetic native build graph and invents the process records. Only
the independently tested original diagnostic reader, original control reader
and complete dependency archive reader have synthetic return values. Their
receipts and admission summaries are not presented as newly verified execution
evidence. The complete native reconstruction and arithmetic are real. Archive
consistency does not authenticate the producer or prove source-to-binary
execution independently.

No native workload was executed by this agent. No historical proof, retained
archive, golden output, performance threshold or acceptance gate was changed.
Only the two assigned new Python files and this report were written. No commit
or push was performed.
