No concrete F2/F3 production blocker found. Six valid independent probes passed:
five synthetic producer checks and one real CLI path-admission check. These

## Review of reachable failure paths

Reviewed all shared producer changes and its explicit new CLI. The ordinary
path resolver rejects nonliteral/symlink-traversing paths, preexisting work and
output paths, and overlapping roots. `execute` also creates output exclusively,
so direct invocation cannot resume into retained output. Native command dispatch
has stable source/helper/tool/dependency/qualification checks before and after
each command, followed by raw output validation, per-process stability, and
final source/tool/dependency/artifact/log/retained-evidence checks.

The finalization path derives qualification from successful outcome and the
complete expected population. The final resource probe demonstrates that all
24 completed observations alone do not produce a passing qualification. The
unchanged bounded process helper retains cleanup, timeout, RSS, log and disk
checks; this audit reviewed those call boundaries but did not create real host
resource pressure or terminate a real GPU/model child.

## Corrected probe error retained honestly

The first source-drift probe selected
`tests/regression/ai_counter_preflight/main.cpp`, which `WarmHarness` does not
copy into its synthetic source directory. Its callback raised `FileNotFoundError`
before any source mutation. An initial assertion requiring a source-stability
message therefore failed. A subsequent broad assertion let that invalid probe
finish as a negative invocation case; it is **excluded from valid evidence**.
Both scripts, logs and the uncorrected receipt remain retained.

The replacement probe first verifies that `sw/kernel/ai/matmul.cpp` exists in
the harness's hashed source inventory and has the frozen kernel digest. It then
changes that actual file only after the last process writes its output. This
corrected probe passed with the precise source-stability rejection and 23
completed processes. No producer change was made to obtain this result.

The final aggregate explicitly identifies and excludes the invalid fixture
probe, replaces it with the corrected observation, and pins every underlying
script/log/result. Its six valid cases do not count the initial failed assertion
or the invalid fixture callback as additional coverage.
