## RTL, pending work and separate controls

This job **does not run an RTL datapath or a backpressure matrix**. The broader
completion contract covers both SimX and processor-RTL runtime host boundaries,
but controlled pending/busy-edge, overlap, sticky failure, RAM/LLC/drain and
teardown cases are separate host fixtures. Likewise, the timing/functional
SimObject cleanup fixtures test abandoned accounting with one executor worker;
they are not native functional SimX or RTL processor executions.
Sources: `docs/designs/simulator_completion_v1.md:33–99,120–173,184–204`;
`ci/project/test_p06_simulator_async_run.py:61–85`;
`ci/project/test_p06_simulator_platform.py:71–80`.

The separate pinned-parent sensitivity producer declares **eight host cells**:
two backend implementations × standard/unknown exception groups × RAM/LLC.
It requires the exact intended behavioral failure, not a timeout or compile
failure. That program is not called by this workflow and explicitly records
`native_execution=false`, `qualified=false` and `acceptance_claimed=false`.
Sources: `ci/project/p06_simulator_parent.py:31–42,95–103,158–174`.

## Source, tool and receipt binding

P04 preparation verifies the workflow SHA before execution. The producer
requires clean source, the frozen profile, unchanged imported helper bytes,
identified tools/interpreter and dependency libraries. It retains source,
generated configuration, compiler records, effective-header observations and
raw logs; validates exact compiler options/include order; and checks source,
tools, dependencies, configuration and products before/after native cells and
again during finalization. Native binaries are identified but not archived.
These checks do not constitute a hermetic inventory of every system header or
dynamic dependency, nor protection against malicious replacement restored
between observations.
Sources: `ci/project/p04_ci_prepare.py:142–182`;
`ci/project/p06_simulator_execute.py:56–91,94–116,202–257,356–436,456–479`.

Each command must have actually started, exited zero, completed cleanup and
retained a log matching its process receipt. Failure or interruption remains
failed/blocked; unfinished cells cannot become passes. The final complete flag
requires both cells to pass, and the CLI returns nonzero otherwise. Workflow
artifact upload runs even after failure. Green status therefore supports the
two declared prerequisite cells only: `qualified` and `acceptance_claimed`
remain false. It does not close counter/no-wrap qualification, warm performance,
P06-A02/A03, vendor or physical-device obligations.
