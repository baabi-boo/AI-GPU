## What unchanged definitions do not establish

There is no direct addition of checkpoint publication calls to the frozen native
interval definitions, and the installed launcher is outside this qualified
native route. **This does not prove performance equivalence.** Checkpoint I/O,
inter-process delays, resource availability, scheduling and other host conditions
can affect a later real run indirectly. Matching measured-source bytes is not
evidence that two executions have identical timing or environmental state.

The full current source and loaded helper identities remain part of the actual
execution binding and stability checks
(`p06_managed_preflight_execute.py:85–107, 369–385, 497–503, 671–727`). Native
admission therefore still requires the selected master revision's own strict
governance/original replay, exact private prerequisites, real resource admission,
fresh complete source-matched execution and independent complete native replay.
Focused failure tests, unchanged hashes and this review cannot replace them.
