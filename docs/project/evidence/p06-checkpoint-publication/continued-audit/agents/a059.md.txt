  SimX jobs with fail-fast disabled. Both jobs are needed for the complete

  3.12.14 and explicitly pinned build packages; this is not arbitrary-host
  qualification (`:125–153`).
- The preparation step passes the provider's `GITHUB_SHA` explicitly (`:179–193`).
  `p04_ci_prepare.py:169–183` compares the checkout to that SHA before and after
  tool relocation, then applies the unchanged clean-source gate. The P05 runner
  independently snapshots the source and rejects dirty/blocked provenance
  (`p05_execute.py:89–97,338–361`; `p02_matrix.py:215–222`).
- The workflow first runs the ordinary P04 native reference and then P05 against
  that exact native build/packet (`p05-python.yml:194–211`). P05 verifies that the
  completed native packet is clean and passing, copies it byte-for-byte, and
  reconciles the native artifact inventories and raw observations against the
  current source and selected variant (`p05_execute.py:363–429`). A green status
  is not obtained merely by finding an old report with a passing label.
- P05 creates a bound sdist, rebuilds its wheel offline without the original
  `VORTEX_AI_BUNDLE` override, creates a fresh copied-interpreter venv, installs
  without indexes/dependencies/bytecode, and hashes installed files against the
  wheel (`p05_execute.py:487–538`). These are actual build/install commands,
  not metadata-only probes.
- The installed matrix runs outside the checkout using the installed venv's
  `python -I -B -m vortex_ai.launch --bundle ... -- p05_installed_check.py ...`
  (`p05_execute.py:539–575`). Thus the new `_run_child` executes its ordinary
  spawn/wait/return path. The checker verifies isolation, venv/package/compiled
  extension locations, immutable build pins and verified loader environment
  (`p05_installed_check.py:222–274`). The runner also rechecks package/interpreter
  identities after execution and joins observations to independent native
  comparisons (`p05_execute.py:563–590`).

The checker requires six matmul runs and ten model runs per selected format,
with 36 installed launches; independent comparison work contributes another

`p05_execute.py:581–589`). Both successful format jobs therefore cover 144

## Provenance and failed results

The runner hashes loaded helpers, source files, tool/dependency inventories,
package prerequisites, native builds, bundle, sdist, wheel and installed bytes;
its repeated `stable()` checks reject changed identities
(`p05_execute.py:60–66,89–97,303–328`). It retains current source/checker/package
bytes and actual commands/logs, then records final source/tool inventories.

Every external command must pass, exit zero and report complete process cleanup
before the runner continues (`p05_execute.py:290–301`). Errors become `fail` or
`blocked`, interruption becomes `fail`, and finalization keeps partial/native
artifacts instead of deleting them (`:591–619`). The CLI returns nonzero unless
the final report is passing (`:658–666`). `acceptance_claimed` and
`phase_complete` start false and are not promoted by this workflow (`:272–277`).
The artifact upload runs with `always()`, includes hidden files, rejects a missing
packet, and names the exact SHA/format/attempt (`p05-python.yml:212–221`).
Uploaded failure evidence remains failure evidence; independent review/replay
is separate from workflow success and retention.

## Cancellation limits

Neither the workflow nor the installed matrix injects PID-directed SIGTERM into
the native checker. The checker's bounded failure cleanup (`p05_installed_check.py:
591–640,678–709`) is not evidence that it ran during a signal termination.
`baseline_process.py:103–128,226–301` controls whole child process groups for
command limits/interruption, which is different from the revised launcher's
single-PID forwarding path. A timeout/interruption is a failed command, not a
passing native cancellation qualification. The new inert-child host regressions
establish their recorded process-ownership behavior; they do not demonstrate
draining a GPU/native operation, descendant supervision, or durable closeout
after SIGKILL.
