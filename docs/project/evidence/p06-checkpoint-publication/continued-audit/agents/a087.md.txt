## Reviewed boundaries

1. **Exact, stable trusted source.** The caller must provide a full lowercase commit ID and canonical absolute checkout root. The observer checks real directory traversal, a supported `.git` locator, exact checkout root/HEAD/index, complete tracked materialization, Git blob identity and executable mode, and closing metadata/file observations. It rejects hidden/sparse/unresolved index entries, untracked files, grafts, replacement refs, executable filters, partial-clone retrieval, ignored Python inputs and local Python caches. Git runs with a sealed environment, hooks/fsmonitor disabled, replacement objects and lazy fetching disabled, and bounded output/duration. Source limits are 32,768 entries, 128 MiB per file, 1 GiB total tracked bytes, 32 gitlinks, and a 30-second observation budget. Sources: `ci/project/governance_replay_source.py:19–29,43–86,107–129,163–211,214–313`; directory enforcement: `ci/project/baseline_packet_io.py:133–201`.

2. **Bound Python helper imports in a separate discovery process.** The collector obtains the selected Git tree, confirms its complete inventory digest/count against the source binding, and gives the child a `.py` path/mode/object-ID map. The child uses `-I -B -S`, a small explicit environment, private HOME/TMPDIR, a new process session, a 60-second collection deadline, 1 GiB address-space limit, and bounded request/result/diagnostic sizes. A tracked source loader opens without following links, checks mode and stable metadata, hashes the exact bytes against the Git blob ID, and compiles those verified bytes. Import checks reject linked/unbound source, nonstandard external/third-party imports, unbound bytecode/native modules, and invalid module specifications; loaded tracked Python sources are rehashed after discovery. Sources: `ci/project/governance_replay_collect.py:22–28,50–63,77–178,182–197,235–260,284–339,361–382`.

## Concrete limits and claim discipline

- Discovery **executes trusted import-time and discovery hooks**, including custom suite iteration and `id()` behavior. Isolation does not turn an unknown checkout into safe input, prevent trusted hooks from deliberately performing other work, or provide a security sandbox. The reviewed reader, its interpreter/standard library and `/usr/bin/git` are trust roots; the source binder does not attest those reader-execution bytes automatically. Preserve their independently selected identities for any concrete replay (`docs/project/governance-artifact-replay.md:12–25,59–65`; `docs/designs/governance_artifact_replay_v1.md:18–25`).
- Symlink rejection is contextual: archive paths/members and Python imports reject links; an ordinary tracked **non-Python** source symlink may be inventoried by hashing its link text without following it. Top-level gitlinks bind pins, not materialized recursive native dependency bytes (`ci/project/governance_replay_source.py:196–211,214–250,276–291`). This review therefore makes no blanket assertion that every tracked symlink is forbidden or native dependency closure is proven.
- Source/archive stability is checked at the described observations; no immutable snapshot or hostile-kernel guarantee is established. The declared byte and collector resource limits are not a hard end-to-end memory/time bound for the complete parent reader. Current artifact size, collection duration, successful source binding and successful replay were not measured here.
- Local success explicitly keeps `provider_authenticated`, `retained_code_executed`, `tests_executed_by_replay`, and native/phase/performance acceptance false. It reconciles recorded execution; it neither authenticates provider origin nor reruns recorded tools/test bodies. Provider repository/revision/run/attempt binding and current original acquisition remain separate obligations (`ci/project/governance_replay.py:191–206`).
- Historical replay, focused tests, this static audit, and local/API tree equivalence cannot replace the final published revision's own complete strict original and independent replay (`docs/project/governance-artifact-replay.md:126–131`).
