## Checks and supporting source

- **Input type and representation:** public `Tensor` accepts exact bytes/bytearray/memoryview, exact integer metadata excluding bool, supported tags, packed positive strides and addressable extents (`python/vortex_ai/_api.py:35-48,230-290`). Native `InputBuffer` independently requires rank one, item size one, explicit unit stride, C contiguity, direct storage, a single `B`/`b`/`c` format, nonnegative exact length, matching shape and a non-null pointer for nonempty input (`python/native/module.cpp:350-385`). Read-only input is accepted through `PyBUF_FULL_RO`.
- **Arithmetic bounds:** native `word_value` rejects non-exact integers and values outside uint32; `supported_shape` accepts only the three fixed shapes before multiplication (`module.cpp:306-329,387-389,664-680`). Consequently the largest input allocation/extent expression is 512 bytes and cannot overflow. The public layer additionally bounds generic tensor extents against uint64 and `sys.maxsize`. Private native calls may use a different bounded-value exception category, but the documented public facade supplies the specified `ValueError`/`OverflowError` distinction.
- **Release and copying:** a successful `PyObject_GetBuffer` immediately sets the RAII release flag. Every validation failure, second-buffer acquisition failure, native failure, status-allocation failure and C++ unwind destroys acquired views (`module.cpp:350-385,677-705`). `ManagedMatmul::submit` synchronously copies A and B into owned byte vectors before queue work (`sw/runtime/ai/runtime.cpp:500-545`), while both native views and the public facade's fresh memoryviews remain held (`_api.py:474-494`). No borrowed Python data pointer is retained by that submission path.
- **Detached result export:** `word_bytes` checks `count <= PY_SSIZE_T_MAX / 4` before multiplication/allocation, then emits each uint32 explicitly in little-endian order into newly allocated Python bytes (`module.cpp:432-447`). Matmul export requires successful completed status and the nonzero expected word count (`766-785`). Model output requires successful inference, closure, comparison, profiling and resource checks (`450-487,1022-1038`); its source is a fixed 64-word array (`sw/runtime/ai/mlp_runtime.h:114`). The public layer rechecks exact byte type/extent and decodes words with explicit little-endian unpacking (`_api.py:583-592,649-657,742-751`). Trace/record strings and status dictionaries are detached allocations.
- **Exception containment:** all exported methods use `boundary`, which catches allocation, standard and unknown C++ exceptions and translates them to Python exceptions; module initialization also catches all (`module.cpp:180-208,1059-1120`). Temporary Python results use RAII. Native submission has its own noexcept catch-to-status handling (`runtime.cpp:552-569`).
