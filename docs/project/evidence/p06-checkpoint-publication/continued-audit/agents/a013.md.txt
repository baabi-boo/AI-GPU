## Regression reproduction

module before changing the writer:

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=ci/project python3 -m unittest -v test_checkpoint_directory_access
```

old directory open. The direct test's two subtests each errored and its final
file-inventory assertion failed because no checkpoint existed; the real P04
consumer also errored. The mode-restoration cleanup completed.
