## Implementation

The existing `load_contract()` / `validate_contract()` path still requires every
one of the **46 original source pins**, exact manifest equality, frozen CSR
class/address checks and the independent 88-operator / 10-model fixture
validation. The command-line interface continues using this strict path, and
`p06_execute.py` is unchanged. The common input and counter logic was factored
without changing the strict path's ordering, bounded file reader, errors or
expected values.

The distinctly named `load_analysis_contract()` /
`validate_analysis_contract()` APIs validate the identical frozen manifest and
all **21 explicitly enumerated interpretation inputs**. The tuple includes the
configuration and CSR definitions, configuration generator, three workload
fixtures, P02 reference/adapter helpers, the P03 operator manifest, P04 model
reference/adapter/contract/manifest, profile, shared argument/profile headers,
and the model's existing contract/host bridge inputs. It is a positive list of
the interpretation dependency closure, not an exclusion list of the three
runtime files changed in this task.

The P04 validator continues checking its additional documentation and license
inputs through the hash-pinned P04 manifest. The P02 loader still reproduces
the leaf fixture from its independent producer. Both analysis and execution
perform the original complete numerical fixture and CSR-table checks.

For analysis, the **seven Python helper modules actually executing** are also
checked for their expected path under the trusted local repository and their
original frozen hash before invoking fixture validation. This covers both P02
and P04 helpers even when the source argument names a separate data tree. No
module is loaded from that data tree or from an evidence archive by these APIs.

The API documentation explicitly states that analysis does not validate an
execution checkout or an archive. A historical archive replayer must separately
check all 46 source pins against retained, digest-verified source bytes. That
separate archive obligation is not removed or replaced by this loader.
