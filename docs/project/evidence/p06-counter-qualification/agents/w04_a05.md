# Wave 04, agent 05 — rehashed qualification binding attacks

## Scope and finding

**F0 — no concrete false-qualification bypass found in these four controls.**
Confidence is high within the tested binding and stability boundary. Evidence
is production-source inspection and executed synthetic complete-packet tests.
No production file, frozen proof, trusted digest, numerical fixture, acceptance
predicate, or historical original was changed. No commit or push was made.

The existing qualified-reader suite already tests simple build/process proof
digest edits, a changed admission source count, missing admission helpers,
all six final stability digests, and a malformed final stability row. This
assignment adds distinct transitive-rebinding and intermediate-check controls
instead of repeating those cases. The independent wave-03 reader review and
the shared fixture were inspected before selecting these tests.

## Executed attacks

All four cases call the public `p06_counter_qualification_replay.verify_view`
entry. The mutated native report is serialized again and supplied with its
new, correct external report SHA-256. Retained member descriptors and the
complete retained inventory are recomputed.

For the three binding-related cases, the fixture also recomputes each affected
build binding, embedded build, process binding, process identity, command
`--qualification-id`, raw transcript echo, parsed observation, retained
observation, command log hash/size, and raw-log inventory. Their rejection is
therefore a semantic mismatch, not an unchanged descriptor or obsolete report
pin.

| Control | Preserved appearance | Required rejection observed |
| --- | --- | --- |
| Cross-policy process binding transplant | Correct format, reviewed proof digest, complete raw records, and repaired echoes; the first process adopts the other policy's binding and therefore shares its identity | `reconstructed process binding` |
| Historical control-summary transplant | Original archive/source pins and all success flags remain; one positive pending-context value is changed and propagated into both builds and all four processes | `reconstructed counter qualification admission` |
| Interior stability drift | Admission endpoints and the final stability row match; a middle checkpoint changes only the control-archive digest | `route stability observation counter_qualification_admission` |
| Equal-count helper substitution | All retained source bytes remain present; the loaded-helper list retains 77 entries by replacing the executing qualification entry with the retained config generator, with all bindings repaired | `executing helpers paths` |

For the interior-stability case, a wrapping observer confirms that all **four
real transcript-validator calls** completed before rejection. This shows that
matching endpoints and a valid final row cannot erase a failed intermediate
observation. The helper-list case rejects before either historical prerequisite
reader is invoked. The transplanted control-summary case invokes both
prerequisite boundaries and rejects disagreement with their returned results.

## Evidence limits

The complete native grammar and transcripts are synthetic test data. The
dependency verifier and both historical prerequisite verifier APIs are mocked
at their documented seams. Binding reconstruction, source/inventory handling,
raw transcript parsing, observation reconstruction, stability checks, and the
public native-report pin check execute the real production readers.

These controls establish neither fresh native execution nor replay of a real
dependency, diagnostic, or separate-control original. They do not authenticate
an untrusted producer or establish Git membership of retained source bytes.
They do not qualify the future warm experiment or change any phase acceptance.
