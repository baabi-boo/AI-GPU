## Concrete choices

- The direct preparation entry requires an existing owned workspace. The
  runbook creates it once, with separate supervisor home/tmp directories and
  fresh stage destinations. It distinguishes the historical five-stage outer
  executor, which requires an absent workspace and has a different contract.
- Every stage uses the same new, reviewed published 40-character source commit
  and checkout, with all eight recursively pinned submodules. The procedures
  stop on failure and preserve earlier successful subpackets without promoting
  the failed attempt.
- The unchanged input guide supplies the five dependency trees, fifteen locked
  archive parts, full GCC/C++ runtime and host tools. The new instructions retain
  Python 3.12.14, sanitized child environments, two build jobs, one worker and
  the original memory/disk/command budgets. They explicitly avoid claiming the
  historical outer 90-minute supervisor for a manually composed route.
- The proof and both prerequisite archive SHA-256 pins are fixed. The dependency
  receipt pin comes from the new completed original's raw report bytes, before
  the qualified entry performs its full admission.
- Packaging selects exactly `dependency-build/` and `native-qualification/`,
  including all regular hidden retention-lock files. It does not archive the
  entire evidence directory or insert review data into the original. The data
  recipe checks every ZIP member against the original and rehashes the selected
  source trees after packaging.
- Replay uses the new reader's exact options, including `--archive` and
  `--source-revision`. It distinguishes the native source snapshot's raw hash
  from semantic source/dependency hashes. External expectations, reader identity,
  separate original prerequisites and exclusive output creation remain explicit.
- Native preflight qualification, inert replay, historical controls, future warm
  execution and phase acceptance remain separately scoped. Failure or a resource
  guard leads to preservation and a fresh adequately provisioned attempt, without
  relaxing limits or editing originals.
