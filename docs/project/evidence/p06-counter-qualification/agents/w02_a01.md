## APIs and guarantees

- `validate_proof(bytes_or_document)` accepts only the fixed byte or semantic
  identity, with bounded JSON types and an independent deep copy.
- `load_proof(path, expected_sha256)` additionally requires the externally
  selected frozen pin and a canonical regular file without symlink or hardlink
  traversal, checking identity and stability while reading.
- `verify_source_projection(proof, descriptor_list)` checks sorted, unique,
  bounded descriptors and all 69 exact required identities. Extra descriptors
  may represent the enclosing complete build inventory; they cannot replace or
  omit a required source.
- `contract()` and `contract_hash()` bind the unchanged dependency/lifetime
  contract, proof identity, exact population and explicitly separate result
  scope. All seven historical qualification/warm/acceptance flags remain false.

The ten premises contain source references and mandatory fresh-process
relationships, not caller-provided success Booleans. Rehashing an altered proof
does not authorize a new semantic contract.
