reset generation one. Run ordinals are exactly 1–33. Their before-reset generations
are exactly 1–33, and after-reset generations exactly 2–34. Every call was really
entered, completed without exception, and began and ended with the platform idle,
no running model, exit code zero and pending reads zero.

Each run's entry equals the preceding completed run plus its output flush.
Each flush begins at that run's exit tick, retains its reset generation and only
advances the tick clock forward. The first prime is included in the same checks;
there is no timing-exclusion exemption. The two MPM halves and each flush form
one exact per-process DCR sequence 1–297, without missing or duplicated entries.
All pending balances before and after those reads are zero.

Every snapshot reads the exact 33 available selectors in order, while the twelve
unavailable entries retain null values and receive no queries. Each available
value is a successful unsigned 64-bit result. All opening aggregates are zero;
the prime and completed-batch values are nondecreasing; completed-batch and
before-release values are equal. This checks all **33 aggregates**. The frozen
source proof maps them to **40 backing components**; the native record does not
pretend to query forty separate selectors.

At each terminal `before_release` vector, queues and buffers are zero and the
device reference count is one. CP and queue submission remain enabled, both
status and error are zero, and retired sequence equals the declared completion
sequence. The before/after retirement values are **1,158 → 1,224**, accounting
for the final 66 half reads. The runtime tail and raw tail register pair agree
with those sequence values. An unpublished head writeback is not used as the
drain certificate.

The final lifetime vector is unchanged across observation and equals actual
destruction entry. In all four processes that entry records 194,112 cumulative

The platform tick clock is a different quantity from the cumulative counters.
Launch reset and finalization legitimately reset that clock. This review does
not impose false monotonicity across those clock resets or infer a new meaning
