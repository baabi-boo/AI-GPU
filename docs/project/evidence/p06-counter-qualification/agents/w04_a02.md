## Review scope and decisions

Reviewed `AGENTS.md`, the complete admission implementation, existing admission
tests and qualification runner tests. The existing tests already exercise late
byte changes in the proof, measured source, helper source, public source
inventory, both prerequisite archives and dependency products. They also cover
failure before launch, between measured policies and at finalization. This
assignment did not duplicate those cases.

The dependency boundary requires
`type(dependency_admission) is dependency.Admission`. It checks the same source
and revision and uses `is True` for both the dependency report and verification
success fields. A subclass without dependency attributes is rejected before
those attributes can be read. Integers and strings cannot stand in for either
success Boolean.

The stable input identity is canonical path, SHA-256 and byte length. Device,
inode, timestamps and link count additionally guard each individual read. A
completed atomic replacement with identical bytes between two reads preserves
the content identity; this is not represented as persistent inode continuity.
Conversely, replacing the path with identical bytes between the initial stat
and open, or during the read, is rejected. The two race controls use actual
files and atomic replacements and intercept only the timing of the normal
open/read operations. They do not supply fabricated stat or digest results.

## Added controls

| Control | Observed result |
| --- | --- |
| Dependency subclass with no initialized admission state | Rejected at exact-type gate before either prerequisite replay |
| `False`, integer `1` or string `"true"` in either dependency success field | Rejected before either prerequisite replay |
| Diagnostic and control archive paths exchanged, original external pins retained | Rejected before either prerequisite replay |
| Hardlink added to the diagnostic input after admission; control path replaced by a symlink to unchanged bytes | Both rejected at the next stability check |
| Measured-source parent directory replaced by a symlink to unchanged contents | Rejected at the next stability check |
| Same-byte replacement before the input descriptor opens | Rejected as changed before reading |
| Same-byte replacement after the first actual read | Rejected as changed while reading |
| Completed same-byte atomic replacement between independent reads | Same content identity retained; replacement inode verified to differ |

## Evidence limits

These are host tooling tests. The reused `AdmissionInputs` fixture constructs
an exact dependency admission object without running its constructor and mocks
its stability method. Diagnostic and separate-control replays return explicitly
synthetic results. Their tiny synthetic archive files are actually hashed, then
the fixture maps unchanged synthetic identities to the reviewed external pins;
changed bytes and alias failures still pass through the real filesystem
validator. Measured source, proof, helper and public-inventory copies retain
their actual bytes and hashes.

This review does not establish historical-original replay, fresh dependency
compilation, native execution, counter qualification, warm performance or
acceptance. There were no commits or pushes by this agent.
