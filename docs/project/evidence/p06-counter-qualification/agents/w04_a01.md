## Independent findings

The public proof boundary validates an independently frozen identity, not just
population totals. Both the byte input and decoded-document input require a
fixed trusted digest. Preserving all 33 selector names, all 40 distinct component
identities, and consistent component-to-selector back references therefore
cannot authorize changed associations. Exchanging CSR coordinates, source
provenance, premise source references, or fresh relationship obligations also
fails despite unchanged population counts.

Nested booleans cannot impersonate numeric zero or one through Python's
`False == 0` / `True == 1` equality. The canonical JSON identity distinguishes
their representations. Tests replace `core_id`, `mpm_class`, `initial_value`
and `component_count` with equality-preserving booleans and require rejection.

The file admission path requires the original byte identity. Duplicate nested
JSON keys that a permissive parser would collapse to the exact reviewed
document are still rejected at this public bytes boundary. These controls do
not claim to reach the duplicate-key parser behind the earlier fixed hash
guard. Reordering dictionary keys is harmless for the already decoded semantic
API; serializing those keys into a different file does not produce an admitted
original. Both sides of that distinction are exercised.

Source projection accepts additional build descriptors, but still validates
every additional descriptor. It rejects traversal, absolute paths, ambiguous
separators, backslashes, NUL/newline/space suffixes, encoded traversal text and a
Unicode separator. Additional descriptors must also have a strict integer size,
lowercase 64-digit digest and unique path. Checking only the 69 selected source
rows would have missed this boundary; the added controls exercise it explicitly.

Caller inspection confirmed that live admission enters through `load_proof`
and retained replay enters through `validate_proof` with retained proof bytes.
The decoded-document API is used for subsequent composition of already frozen
premises; it does not make a fresh native execution claim.
