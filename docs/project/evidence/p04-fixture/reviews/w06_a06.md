## Source and numerical review

The producer fixes original synthetic weights, seeds, update order, matrix
shapes and the two encodings. It computes direct integer matrix products, with
an independent P02 integer encoder; it never calls production tensor arithmetic.
All logical inputs and weights lie in [-2,2]. Hidden prefixes are bounded by
64, bridge values by [0,64], and final prefixes by 1,024. Those integers are
exactly representable in the declared formats and remain in the accepted P02
alignment window. The numerical test reads the serialized operands and compares
all 1,920 scalar outputs across 6,400 ordered quartets to the independent P02
reference, including no-discard assertions. Separate literal and decoded-input
tests prevent a producer-only consistency check from being the only oracle.

Five families in both FP16 and BF16 cover dense signs, negation/nonlinearity,
zero, basis features and distinguishable output row blocks. The split boundary
formula and row-offset checks distinguish repeated/swapped output halves. This
is a deterministic correctness workload, not trained-model accuracy evidence.
No inherited numerical tolerance or golden was changed.

The host helper accepts exactly 128 actual FP32 words and a supported dtype.
Its exponent checks bound every subsequent shift; the largest integer exponent
is six, below both destination fraction widths. Sign handling occurs only after
finite/integral/domain validation, so ReLU cannot hide negative malformed input.
Both signed zeros become positive zero. Every failure returns a fresh zeroed
array and leaves the input untouched; no prefix escapes. All byte stores are
explicitly little endian. The helper has no heap allocation, dispatch, CPU
matmul fallback, or dependency on sim/ or hw/ implementation code.

The C++ harness tests the entire 129-value legal domain at every position in
both formats, adjacent fractional encodings, both signs of exceptional values,
malformed extents and dtypes, row boundaries, actual fixture inputs, and
late-array rejection without partial output. Legal-domain coverage is 258
helper calls spanning 33,024 element/position/format combinations; it is not
33,024 helper calls. The Python wrapper requires a C++17 compiler and UBSan,
uses bounded subprocesses, and checks unchanged source identities.
