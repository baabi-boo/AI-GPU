## Findings

1. **Generation is reproducible and fully specified.** W1 contains 128 logical values in a 16×8 matrix and W2 contains 32 in an 8×4 matrix: exactly 160 weights. Separate streams use seeds `0x50403401`, `0x50403402` and `0x50403410`. The three xorshift operations and masks precede each `s % 5 - 2` emission. The spec's masked left-shift form is equivalent to the producer's mask-after-XOR form because the state is bounded to 32 bits.
2. **All input families are explicit.** The exact ordered case inventory is five FP16 cases followed by the same five BF16 families: seeded dense, negated dense, zero, signed basis and split boundary. All 2,560 serialized input elements decode to the independently reconstructed family definitions. The revised split formula includes the row-block term `3*(r//8)`.
3. **Logical generation and storage layout agree.** The 160 logical weights are generated in row-major order and packed in column-major device-input order. All 320 per-format decoded weight elements match that transformation. Earlier input-format elements occupy the low 16 bits; raw hashes use little-endian 32-bit bytes. X/H/R/Y have their declared row-major representation.
4. **Counts and identities agree.** The fixture is **92,301 bytes**. Its SHA-256 is `d22a899827afb3e8c22a528fc6a27fd12ff114ef39caf9ffa0cccd77e849cd03`. All **44 raw tensor hashes** validate over **4,000 uint32 words / 16,000 bytes**; all **17 manifest source pins** match the same committed tree. X/H/R/Y arrays have 128/128/64/64 stored words per case, and W1/W2 have 64/16 words per format. Manifest case IDs/counts and the three planned native shapes match the fixture/spec.
5. **Provenance is documented without an external model dependency.** The weights and inputs are directly derived from the stated generator and formulas. The producer imports only standard-library modules and the inspected repository-local independent integer encoder; there is no external download, dataset, pretrained weight or tokenizer path. The fixture and manifest declare Apache-2.0 and pin the repository LICENSE, which is byte-identical to the initial baseline. This is a source derivation/provenance finding, not an independent legal title opinion.
6. **Claims remain bounded.** The model has no bias, softmax, sequence state or tokenizer and makes no trained-quality claim. ADR-005 records the actual coding-agent engineering decision under the user's development instruction, without inventing a separate human approval. The manifest declares `source_present`, `execution_available: false`, no GPU execution claim and unearned A02/A03. Thirty native launches are a planned workload count.
